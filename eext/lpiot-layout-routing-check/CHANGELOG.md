# 更新日志

## 0.4.0

- **出图前检查（新闸门 G5）**：新增“丝印”页。布线定稿后逐项回答 20 个决定（丝印工艺、字高、线宽、离焊盘距离、位号策略、文字方向、极性与 1 脚标记、接口按键说明、板名版本、警示、认证标志、订单号位置、底面丝印、编号方式、反标、泪滴策略、射频差分去泪滴、泪滴执行记录、丝印截图、极性核对），每项附推荐值和为什么要问；检查丝印 SLK、位号编号 ANN、泪滴 TDR（与源码仓库 `finish_lint.py` 一致），结果可记录为 G5 依据。原来的交付验收改为 G6，旧的设计确认自动迁移。
- **能力边界**：本扩展是检查图、改图，不是完全自由的自动布线。MCP `routing_gate` 必须点名这一批网络（每批不超过 8 个、在已确认的优先级里、走线里不能夹带别的网络），“全部”“剩下的”一律拒绝；AI 解读的提示里也写明边界。
- 本地桥新增 `finish_check`。

## 0.3.0

- **改名为“布局布线检查助手”**（扩展名 `lpiot-layout-routing-check`），菜单增加“快速布局检查”。
- **布线优先级逐档确认**：按网络名、连接的器件（位号与型号）和网络类把网络分成 9 档，每档写明理由、每个网络的作用、走法和规则；可以让自己配置的大模型结合器件型号修正。面板里逐档确认，点一档就在板子上只亮这一档的网络并流动显示；挪动网络或改走法后，从这一档往后要重新确认。所有档位确认后才能确认 G4。
- **布局检查补全**：按型号识别 IMU、磁力计、温湿度、气压计、麦克风、DCDC、LDO、充电芯片和无线 SoC，nH 级电感按射频匹配处理；新增 IMU 离板边与应力源（LAY-11）、传感器与晶振离热源（LAY-12）、磁力计（LAY-13）、电感与敏感传感器（LAY-14）、电源流向（LAY-15）。
- **本地联动**：本地桥改为“枢纽 + 转发端”，多个 AI 客户端共用一条编辑器连接；HTTP 接口必须带令牌（`~/.lpiot/bridge.json`），拒绝来自浏览器网页的请求；扩展上报协议版本，连过一次后自动重连；新增 `board_export`（导出铜皮数据包，可写到本机文件）、`priority_draft`、`bridge_status`。源码仓库提供 Python 客户端 `scripts/eda_bridge.py`（导出、取回 / 推送设计确认、梳理优先级、与 Python 规则交叉核对）。
- **新演示板**：50 × 32 mm 的 BLE 运动传感器节点，走线全部为 135° 拐角，只留几处真实问题；修复后没有直角。演示动画重新录制。

## 0.2.0

- **不接受直角拐角**：新增 RTG-04（P0，所有网络类含电源、地线和射频），拐角只允许 135°；写入前闸门同样拦截直角；修复器最后一遍把所有网络上的直角斜切成两个 135° 拐角，切不了的列为人工处理。指标 VF-17 改为“锐角与直角”。
- **上架规范**：横幅改为 64:27 JPEG；吐司提示改用 `sys_Message.showToastMessage`（`sys_ToastMessage.showMessage` 已弃用）；补全 extension.json 字段的英文翻译；新增 `npm run check:store`，按官方开发指南自检 extension.json、图标、横幅、菜单、多语言、README、打包内容和隐私信息，`npm run build` 会自动执行。
- **设计确认（强制）**：新增“设计确认”页，按 G0 需求与工艺 → G1 板框外壳与固定件 → G2 功能分区（看过布局截图）→ G3 布局检查 → G4 布线规划 → G5 交付验收逐级填写；每一级由用户手动输入确认码并在编辑器弹窗里再确认一次。前面的内容一改，后面的确认自动失效。设计确认按工程保存在本机。
- **写回受闸门控制**：G0–G4 未放行时，“应用修复”、MCP `routing_fix_apply` 和 `routing_gate` 一律拒绝；AI 代理发起的写回始终弹窗请用户确认。AI 解读在闸门未放行时只评审已有走线、指出还缺的设计信息。
- **布局检查**：新增“布局”页和“布局检查”按钮，对照设计确认内容检查板框、重叠、固定件贴边与位置、功能分区、禁布区、天线在板边与 3 mm 净空、天线 / 电感 / 晶振 / 电池 / 连接器间距、去耦与晶振负载电容距离（LAY-01…10、RTP-01…08，与源码仓库 `layout_lint.py` 一致）。结果可记录为 G3 依据。
- **布局动画**：功能分区依次扫入，器件按所属功能块着色落入；选中问题时显示目标位置虚框、器件在原位与目标之间滑动的移动示意和流动箭头，间距问题显示两侧辐射的“场”和实测 / 要求距离，禁布区和天线净空用流动斜线标出。
- **本地 MCP 桥**：新增 `design_brief_status`、`design_brief_get`、`design_brief_update`、`layout_check`。代理可以读取和填写设计确认内容，但没有确认工具。
- 布线检查结果可在“结论”页记录为 G5 依据。

## 0.1.0

首个版本。

- 布线检查与评分：任意角度、锐角拐角、锐角 T 分支、短段、Z 形抖动、斜出焊盘、线宽突变、悬空线头、圆弧豁免；
  线宽下限、过孔预算、盘中孔、换层回流过孔、绕行率、晶振线长、2 层板底层跳线、层方向、地平面、成束、密度；
  14 项指标加权评分（VF-16…30），任一 P0 即不通过。
- 走线原则：就近（去耦电容、电容与芯片间过孔、地焊盘过孔、负载电容、ESD、串阻）、差分对（同层、耦合、线距、等长、过孔成对、对内穿线、对外间距）、
  布线优先级倒挂、攻击 / 敏感网络隔离、裸露焊盘过孔、多地网络；推荐布线顺序。
- 面板动画：扫描入场、违规脉冲、电流 / 信号流动与差分对同步流动、回流路径、去耦回路面积、布线顺序回放、修复前后形变。
- 修复预览：重叠合并、悬空线头删除、直线 / 肘形 / 三段式 / 局部八方向 A* 重建，保持连通和间距；确认后写回，放在一个可撤销的操作里。
- AI：接入自己的 Claude 或 OpenAI 兼容模型做整板解读和单条问答；本地桥（HTTP / MCP）让 Claude Code 等代理调用检查、定位和修复。
