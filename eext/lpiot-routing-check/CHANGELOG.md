# 更新日志

## 0.1.0

首个版本。

- 布线检查与评分：任意角度、锐角拐角、锐角 T 分支、短段、Z 形抖动、斜出焊盘、线宽突变、悬空线头、圆弧豁免；
  线宽下限、过孔预算、盘中孔、换层回流过孔、绕行率、晶振线长、2 层板底层跳线、层方向、地平面、成束、密度；
  14 项指标加权评分（VF-16…30），任一 P0 即不通过。
- 走线原则：就近（去耦电容、电容与芯片间过孔、地焊盘过孔、负载电容、ESD、串阻）、差分对（同层、耦合、线距、等长、过孔成对、对内穿线、对外间距）、
  布线优先级倒挂、攻击 / 敏感网络隔离、裸露焊盘过孔、多地网络；推荐布线顺序。
- 面板动画：扫描入场、违规脉冲、电流 / 信号流动与差分对同步流动、回流路径、去耦回路面积、布线顺序回放、修复前后形变。
- 修复预览：重叠合并、悬空线头删除、直线 / 肘形 / 三段式 / 局部八方向 A* 重建，保持连通和间距；确认后写回，放在一个可撤销的操作里。
- AI：接入自己的 Claude 或 OpenAI 兼容模型做整板解读和单条问答；本地桥（HTTP / MCP）让 Claude Code 等代理调用检查、定位和修复。
