      布局规划器

      1. 拾取主器件。单击托盘或板上的器件把它拿起来，它的去耦电容、晶体等卫星器件会跟着悬浮；再单击放下，卫星自动落到最近的合适位置。想看卫星环绕、落地飞落等动画，点工具条上的"动效"打开。
      2. 看反馈。右侧实时显示布线难易和规则问题，每次移动都会说明指标为什么变了。
      3. 导出。摆好后导出布局 JSON，交回给 Claude 做正式的 Layout 评审；也可以把它拖进单独的"布局布线验证器"页面，先看电流回流、电磁和温度的估计。

      这个工具来自开源的低功耗 IoT 硬件设计 skill。觉得有用，欢迎在 GitHub 上 Star 或 Fork，方便获取后续更新、提交改进。

      先选定板子尺寸

      板框由外壳决定。选好尺寸再开始摆放器件。

      操作说明

      拾取 / 放下器件左键单击拾取，器件和它的卫星跟随光标悬浮；再次单击落地。也可以按住拖动
      放回托盘 / 取消拾取拾取中点击托盘 / Esc
      旋转 90°R（拾取中也可以按 R 或右键）
      换面F
      锁定 / 解锁L
      放回托盘Delete 或 Backspace
      微调方向键（0.5 mm），Shift + 方向键（5 mm）
      临时关闭吸附按住 Alt
      平移 / 缩放拖动空白处、中键或 空格 + 拖动 / 滚轮
      旋转视角（仅 3D）右键拖动
      2D / 3D 切换T
      翻板B
      动画效果工具条"动效"按钮开关，默认关闭；关闭时卫星静止排在被拾取器件周围
      撤销 / 重做Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z
      采纳朝向建议Enter
      取消选择Esc

      触屏：单指拖器件，双指缩放和平移；选中器件后用上方的按钮旋转、换面、锁定。托盘中的器件获得焦点后按 Enter 可直接放到板上。

      指标是启发式估计，只用于比较两种摆法；默认规则参数是典型值，器件手册给出具体数值时在项目数据中覆盖。
