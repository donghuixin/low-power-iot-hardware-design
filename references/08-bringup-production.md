# 可测试性、Bring-up、认证与量产

硬件设计的最后一部分工作是让板子"能被调试、能被测量、能被生产"。这些要求必须在原理图和 layout 阶段落实，板子回来之后才想起来就只能飞线。

## 1. 设计阶段要留的后路

| 目的 | 设计措施 |
|---|---|
| 测功耗 | 电池入口和各路电源串联 0 Ω / 跳线；能在不接调试器的情况下运行 |
| 定位漏电 | 每个可疑支路（传感器电源、分压器、LED、电平转换器）可单独断开 |
| 调试固件 | SWD/JTAG、复位、日志串口引出 |
| 调射频 | π 型匹配位置、传导测试点 |
| 改设计 | 关键上下拉、使能、地址选择用独立电阻；预留 DNP 位 |
| 量产烧录与测试 | 针床测试点或板边接口；板上有版本标识 |
| 故障恢复 | 不拆机复位手段；进入下载/恢复模式的方法 |

第一版原型可以比量产版多放测试点和 0 Ω 电阻，验证后再精简。

## 2. Bring-up 顺序

每一步通过后再进行下一步，避免一上电就损坏器件。含高压发射、高速 ADC/AFE、LVDS 或 FPGA 的板子另按 `25-mixed-signal-bringup.md` 的分级顺序。

1. **不上电检查**：目检焊接、极性、桥连；用万用表测各电源对地电阻，排除短路。
2. **限流上电**：用可调电源代替电池，限流设置为略高于预期电流，逐步升压到标称电压，观察电流。电流异常立即断电，用热成像或手指找发热器件。
3. **测各路电压**：稳压器输出、基准、被开关域在使能前后的电压。用示波器看上电波形和纹波。
4. **主控最小系统**：连接调试器识别芯片 → 烧录最小程序 → 确认高频与低频时钟起振、频率正确。
5. **基线睡眠电流**：烧录"所有外设不初始化、所有引脚置于低功耗状态、进入最深睡眠"的固件，断开调试器测电流。这个数应接近预算中的硬件基线。
6. **逐个外设**：一次启用一个，确认通信、功能，以及启用和关闭后的电流变化。
7. **射频**：先测传导功率与频偏，再调天线匹配，再测辐射距离和手机连接。
8. **电源极限**：用可调电源扫电压到最低工作点；用电池模拟器或串联电阻模拟高内阻电池，观察射频发射时的电压跌落和欠压行为。
9. **充电**：充电电流、终止、温度保护、边充边用。
10. **环境与长期**：高低温、长时间运行、ESD。

## 3. 常见故障排查

### 睡眠电流高于预算
1. 确认测量方法：调试器已断开、串口线已拔、测量仪器量程和负担电压合适。
2. 用空固件（见上）区分硬件问题和固件问题。
3. 硬件侧逐项断开：
   - 逐个摘掉 0 Ω 给各支路断电，看电流降多少。
   - 测量每个"应当已断电"的电源域是否真的为 0 V。不是 0 V 就是反灌，查所有连到该域的信号。
   - 测量每个上下拉电阻两端的电压，有压差就有电流。
   - 检查悬空输入：用手指或镊子触碰引脚，电流变化明显的就是悬空节点。
   - 检查外置 Flash 是否进入深度掉电、传感器是否进入待机。
   - 检查稳压器是否工作在预期模式。
4. 电流随时间缓慢变化或随湿度变化：表面漏电，清洗板子。
5. 电流随温度明显上升：半导体漏电（TVS、肖特基、MCU）。

### 射频距离短或连接不稳定
1. 传导功率是否正常——不正常则查匹配、电源、晶体频偏。
2. 传导正常而辐射差——天线问题：净空区、地平面尺寸、外壳和电池的影响，重新调匹配。
3. 发射正常而接收差——板上噪声落入接收频段：关闭 DCDC、降低数字接口速率或驱动强度逐项验证；检查电源纹波。
4. 仅在某些姿态或佩戴时差——人体遮挡与天线方向性，属于天线位置问题。
5. 仅在电池末期差——发射时电压跌落。

### 偶发复位或死机
1. 示波器监测电源，触发在跌落沿：是否在射频发射、电机启动、被开关域上电、Flash 擦写时跌到欠压阈值。
2. 复位脚是否受干扰：走线长、无滤波、靠近噪声源。
3. ESD：接触放电后复位或死机，查保护与接地。
4. 读出复位原因寄存器，区分欠压、看门狗、引脚复位、软件复位。
5. 晶体停振或启动失败：低温、负载电容不匹配、驱动裕量不足。

### 上电不启动或偶发不启动
- strapping 引脚电平被外部电路改变。
- 电源上升太慢或非单调，上电复位未正确产生。
- 电池接触抖动。
- 被反灌的域没有完全掉电，芯片未复位。

### 测量值异常
- ADC 读数偏低或与采样率有关：源阻抗过高，采样时间不足。
- 传感器读数随射频发射或 LED 脉冲跳变：电源或地耦合。
- 温度读数偏高：自发热或板上热源。
- IMU 零偏漂移或批次差异大：安装应力、焊接应力、温度梯度。

## 4. 认证

在阶段一就确认目标市场，因为它影响器件选择和天线方案。

| 类别 | 内容 |
|---|---|
| 无线电 | 美国 FCC、欧盟 CE-RED、中国 SRRC、日本 TELEC/MIC、韩国 KC 等；使用已认证模组并遵守其使用条件可大幅简化 |
| 协议联盟 | Bluetooth SIG 认证、Wi-Fi Alliance、Matter/Thread、LoRaWAN、蜂窝运营商入网 |
| EMC 与安规 | 辐射/传导发射、抗扰度、ESD；带充电器或市电的产品有安规要求 |
| 电池 | UN38.3 运输测试、IEC 62133 等 |
| 环保 | RoHS、REACH |
| 特定领域 | 医疗、汽车、防爆、儿童用品各有专门法规 |

硬件上的准备：射频传导测试接口；固件支持定频发射等测试模式；预扫发现超标时可调整的滤波和屏蔽位置。

## 5. 量产

- **烧录**：离线烧录器 + 针床，或贴片前预烧；烧录时间影响产能。
- **产测**：电源电压、睡眠电流（最有效的单项检测，能发现大多数焊接与器件问题）、各传感器自检、射频功率与频偏、按键/LED、充电功能。
- **校准**：晶体频偏、IMU 零偏、ADC 增益、射频功率；校准数据的存储位置与防误擦。
- **序列号与密钥**：写入方式与追溯。
- **电池**：装配后进入运输模式；出货电量（锂电池通常 30–60%）。
- **BOM 管理**：关键器件的替代料提前验证，特别是晶体、电感、MLCC（不同厂商的偏压特性不同）、天线。
- **版本控制**：PCB 上有版本号，硬件版本可被固件识别（如用几个电阻配置的 ID 引脚——注意这些电阻不要形成恒定电流，读完后把引脚改为无上下拉）。
