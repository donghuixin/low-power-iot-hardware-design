# 布局布线验证器

布局布线验证器是和布局规划器分开的单文件网页（`assets/layout-verifier.html`）。它读入摆好的布局（规划器导出的布局 JSON），在板上做三类定性但有物理依据的验证：

- **电流与回流**：选一个负载，看它的供电从电源起点流过来、回流从地脚流回去的路径，粒子发光亮度随电流密度变化。
- **电磁**：干扰源（天线、射频线、开关节点、电感、时钟）在板上的受扰地图，以及电源/地平面对的谐振模态（起伏的振型、节线和频率）。
- **温度**：板上温度分布，可逐个器件加散热片、改风速、改环境温度、密闭外壳，左右分屏对比改动前后。

它分两个阶段，用的是同一个页面：

| 阶段 | 时机 | 输入 | 结论的性质 |
|---|---|---|---|
| P（布线前） | 布局摆好、还没布线 | 布局 JSON（含可选的 `verify` 块） | 按引脚朝向和可走通道做概率估计；结论前加"估计："，等级最高到 P1，用来判断摆放方向和指导布线 |
| R（布线后） | 板子布完线、铺铜已填充 | 布局 JSON + 铜皮数据包（`extract_copper.py` 生成） | 在真实铜皮上做简化求解；按模拟 / 数字 / 电源分组只解相关铜皮，结论可直接写进 Layout 评审 |

页面不做全波电磁仿真，也不替代 SI/PI 工具。它的用途是在几秒内告诉用户"问题大概在哪、往哪个方向改会变好"，并且每条结论都写明所依据的假设。

## 1. 何时使用

- 布局规划器导出布局 JSON 之后，进入阶段三之前：用阶段 P 看供电和回流的大致走向、射频与敏感器件的距离、热点位置，在布线前改摆放。
- 用户在 EDA 里布完线以后：用阶段 R 把实际铜皮拿进来复核瓶颈、压降、过孔电流、射频参考平面、并行耦合、地铜孤岛和平面谐振，结果并入阶段三的评审报告。
- 用户问"这块板热不热""加散热片能降多少""天线会不会干扰 IMU"一类问题时，用它做直观演示。

可以跳过：两三个器件的小板；只有直流低速信号且没有发热器件的板。

## 2. 生成页面

```bash
# 布线前：读入布局 JSON（规划器导出的即可）
python scripts/make_layout_project.py my-project-layout.json --verifier            # → my-project-layout-verify.html
# 布线后：再给出铜皮数据包
python scripts/make_layout_project.py my-project-layout.json --verifier --copper copper-pack.json
```

`assets/layout-verifier.html` 内置示例（`assets/layout-verify-example.json`），可直接打开试用。用户也可以把布局 JSON 和铜皮数据包直接拖进页面，或用"打开"按钮载入；载入铜皮数据包后页面切换到阶段 R。

页面离线运行，计算放在 Web Worker 里，界面不卡。动效（粒子、波纹、振型）可以用工具条"动效"关闭；帧耗时持续偏高时页面会自动降级（粒子减半 → 去掉拖尾 → 静态流线），也可以手动开"性能模式"。

修改页面源码（`assets/layout-verifier/src/`）后重新构建：`python scripts/build_layout_verifier.py`。验证器复用规划器的 `geometry.js` 和 `model.js`，不复制。

## 3. `verify` 块：电源、负载、功耗、干扰源

在项目 JSON 顶层加一个可选的 `verify` 对象。每个字段都可省略，省略的按默认值补全，页面底部的假设栏和导出报告的 `defaults` 会列出哪些是默认值。写给用户的项目，至少把**负载电流**和**功耗**按器件手册填上，默认值只够看方向。

```json
"verify": {
  "gnd_net": "GND",
  "sources": [{ "net": "VDD", "part": "BT1", "pin": "PLUS", "gnd_pin": "C", "v": 3.0 }],
  "loads": [
    { "part": "U1", "pin": "VDD", "net": "VDD", "i_avg_ma": 6, "i_peak_ma": 16, "kind": "rf", "f_hz": 2.4e9 },
    { "part": "U4", "pin": "VDD", "i_avg_ma": 3, "i_peak_ma": 15, "kind": "dc" }
  ],
  "thermal": [{ "part": "U5", "p_w": 0.45, "theta_jb": 18, "tj_max": 125 }],
  "emitters": [{ "part": "ANT1", "kind": "antenna", "f_hz": 2.4e9 }, { "net": "SW", "kind": "switch_node", "f_hz": 2e6 }],
  "victims": [{ "part": "U2", "kind": "imu" }, { "net": "ADC_IN", "kind": "analog" }],
  "stackup": { "planes": [{ "layer": 1, "net": "GND" }, { "layer": 2, "net": "VDD" }], "cu_oz": [1, 0.5, 0.5, 1], "h_mm": 0.2, "er": 4.4 },
  "plane_cuts": [{ "x": 20, "y": 10, "w": 1, "h": 15 }],
  "env": { "ta_c": 25, "airflow_m_s": 0, "sealed_k_per_w": 0, "contact_limit_c": 43 },
  "rules": { "VF-02": { "max_pct": 3 } }
}
```

| 字段 | 含义 | 省略时 |
|---|---|---|
| `sources` | 每个电源网络的起点（器件、引脚、地脚、电压） | 按角色优先级选：LDO / DCDC / 充电 / 电池 / 连接器；电池 3.0 V，其余 3.3 V |
| `loads` | 负载：平均与峰值电流、`kind`（`dc` / `rf` / `switching`）、频率 | 电源网络上非电源器件，按角色给典型电流；峰值取平均的 3 倍 |
| `thermal` | 发热器件功耗、θjb、Tj 上限 | 用 `heat_mw`，没有就用负载电流 × 电压；θjb 按封装查表，Tj 上限 125 °C |
| `emitters` | 干扰源及相对电平（dB，天线 = 0） | 天线、射频网络、开关节点、DCDC 电感、时钟网络 |
| `victims` | 敏感对象 | IMU、磁力计、麦克风、ADC 等敏感角色，晶体，模拟网络（电池不算） |
| `stackup` | 平面层与网络、各层铜厚、介质厚度、介电常数 | 4 层：L2 = GND、L3 = 主电源；6 层再加倒数第二层地；2 层没有平面 |
| `plane_cuts` | 阶段 P 用：地/电源平面上的槽或分割（矩形，mm） | 无 |
| `env` | 环境温度、风速、密闭外壳热阻、外壳接触温度上限 | 25 °C，自然对流，不密闭，不检查接触温度 |
| `rules` | 覆盖规则阈值（见第 6 节） | 用默认阈值 |

布局规划器导出布局 JSON 时会保留 `verify` 块。

## 4. 布线后：提取铜皮

```bash
# KiCad 6–8：先在 KiCad 里按 B 填充全部铺铜再保存
python scripts/extract_copper.py board.kicad_pcb --project my-project-layout.json -o copper-pack.json
# 嘉立创 EDA / Altium / 其他：导出 Gerber（铜层按叠层顺序）、板框层和 IPC-D-356 网表
python scripts/extract_copper.py --gerber top.gtl in1.g2 in2.g3 bottom.gbl --outline board.gko \
    --ipc356 board.ipc --project my-project-layout.json -o copper-pack.json
```

- 嘉立创 EDA 专业版：导出 Gerber 时勾选"IPC 网表"（IPC-D-356A），按第二种用法处理。
- `--project` 用来取网络类别（电源、射频、模拟等）；不给时按网络名猜（GND、VCC、RF、ADC、CLK……），可能分错，报告里要提示。
- 繁重的几何处理在脚本里离线完成：每层按 0.05 mm 画成网络编号位图，再降采样到求解网格（长边约 200 格，可用 `--cells` 调整）。浏览器只拿到按分组压缩的覆盖率，一般几十 KB。
- 数据包同时带有离线检查的结果：射频线下方相邻层的地覆盖率与地孔围栏间距、模拟线与数字线的并行段、各层地铜的连通性（孤岛）。
- 需要 Python 的 numpy、scipy、Pillow。

阶段 R 以数据包里的板框和器件位置为准（覆盖布局 JSON 里的值），网络名必须与原理图一致，否则会报"找不到焊盘"。

## 5. 三类验证怎么算

**电流与回流**
- 阶段 P：在可走区域上做 16 条带随机扰动的 A* 路径（引脚出线方向有代价），按长度加权叠成概率图，得到最可能的路径、走线通道宽度和路径离散程度；电源网络有整层平面时直接在平面上求解。回流按负载类型区分：高频（`rf`、`switching`）回流贴着去程走，用镜像核函数表示；平面有缺口时重新在带缺口的地平面上求解，得到绕行；没有整层地时按走线估计。去耦电容只算接在同一个电源引脚上的。
- 阶段 R：在该网络的多层铜皮上求解（每格电导 = 覆盖率 × 片电导，过孔按 1 mΩ 连接相邻层），电源起点固定为 0 V，负载焊盘抽出电流；地网络同样求解得到回流。由此得到每段导线的实际电流、压降、过孔电流，以及高频负载的供电铜皮下方有多少比例缺少相邻地层。
- 回路面积按去程与回流路径围成的面积加上去程长度 × 介质厚度估算。

**电磁**
- 受扰地图：各干扰源贡献叠加。近场按 r0² / (r0² + r²) 衰减，超过 λ/2π 后按 1/r；在地平面另一面再衰减 30 dB，有屏蔽罩衰减 20 dB，天线背面衰减 6 dB。敏感对象按所在位置的电平分级：高 ≥ −20 dB，中 ≥ −35 dB。
- 平面谐振：在电源/地平面对的实际形状上（阶段 R 用真实地铜）求 Neumann 边界的本征模态，f = √λ · c / (2π √εr)。列出最低几个模态，检查是否落在干扰源频率（时钟取前 5 次谐波）±10% 内，以及干扰源或敏感对象是否在振腹附近。

**温度**
- 二维板级热传导：每格导热 = Σ 各层铜覆盖率 × 385 W/m·K × 铜厚 + FR4；两面对流 h = 10 × (1 + 2.5 √v) W/m²K。散热片按额外对流处理，密闭外壳抬高环境温度，"整板铺铜"按 80% 覆盖率计算。
- 器件结温 Tj = 板温 + P × θjb（加散热片时 θjb × 0.6）。阶段 R 用真实铜覆盖率。

所有数值都是简化模型的定性结果。相对比较（改动前后、方案 A 与 B）比绝对值可靠。

## 6. 规则 VF-01 … VF-14

阈值可在 `verify.rules` 里覆盖。"对应条目"指 `references/checklists.md` 中 layout 清单的条目。

| 规则 | 名称 | 默认等级 | 触发条件 | 阶段 | 对应条目 |
|---|---|---|---|---|---|
| VF-01 | 电流瓶颈 | P1 | P：可走通道窄于 IPC-2221 所需线宽；R：某段导线宽度小于按实际电流算出的线宽 | P / R | PI-05 |
| VF-02 | 直流压降 | P1 | 去程加回流压降 > `max_pct`（2%） | R | PI-05 |
| VF-03 | 过孔电流 | P2 | 单个过孔 > `max_a`（0.5 A） | R | PI-05 |
| VF-04 | 回路面积 | P1 | 走线供电时回路 > `max_mm2`（20 mm²）；同一引脚上 `max_decap_mm`（3 mm）内没有去耦电容 | P | PI-04 |
| VF-05 | 回流绕路 | P1 | 回流被平面缺口挡住、绕行长度 > `max_ratio`（1.5）倍；R：高频负载的供电铜皮下方超过 5% 没有相邻地层，或地不连通 | P / R | SI-01 |
| VF-06 | 共用回流 | P2 | 高频或大电流负载的回流经过敏感对象下方：附近回流密度 ÷ 最大回流密度 > `max_overlap`（0.3） | P | PI-07 |
| VF-07 | 受扰等级 | P1 | 敏感对象受扰 ≥ `high_db`（−20 dB） | P / R | SI-06 |
| VF-08 | 射频参考平面 | P1 | 射频线下方有完整地的长度比例 < `min_ref`（95%）；地孔围栏间距 > λ/20（P2） | R | RF-06 |
| VF-09 | 并行耦合 | P2 | 模拟线与数字线同层并行长度 ÷ 间距 > `max_ratio`（20） | R | SI-06 |
| VF-10 | 平面谐振 | P2 | 某模态在干扰源频率 ±`band`（10%）内，且干扰源或敏感对象位于振腹（归一化振幅 > `antinode`，0.7） | P / R | PI-08 |
| VF-11 | 结温 | P1 | Tj > `warn_frac`（0.9）× Tj 上限（超过上限为 P0） | P / R | THM-01 |
| VF-12 | 怕热器件 | P2 | 敏感对象和电池处板温比环境高 > `max_rise`（20 K），或器件两端温差 > `max_grad`（5 K） | P / R | SEN-02 |
| VF-13 | 表面温度 | P0 | 板面最高温度 > `env.contact_limit_c`（未设置时不检查） | P / R | THM-01 |
| VF-14 | 地铜孤岛 | P2 | 某层地铜（> 1 mm²）经过孔也连不到主地 | R | PI-08 |

阶段 P 的结论标题前加"估计："，等级最高到 P1。

## 7. 页面功能

- **顶部**：阶段标签（布线前 · 估计 / 布线后 · 简化模型）、三个标签页、动效开关、性能模式、打开、导出 PNG、导出报告。
- **电流与回流**：左侧选负载，可分别显示去程（暖色）和回流（冷色）；阶段 P 有"假如"叠层切换（按项目 / 2 层 / 4 层），用来演示加地平面后回流怎么变。右侧列出电流、去程方式、回流方式、长度、回路面积、建议线宽、压降、附近电容。
- **电磁**：受扰地图（可选正面 / 背面，可只看一个干扰源，干扰源有扩散波纹，敏感对象按等级脉动）和平面谐振（逐个模态显示起伏的振型、节线和频率）。
- **温度**：逐个器件选散热片（0.05 / 0.1 / 0.25 W/K）、风速、整板铺铜、环境温度、密闭外壳；"对比"打开左右分屏，分割线可拖动，标注显示"Tj 原值 → 改后"。等温线叠加显示。
- **3D 展示**：工具条的 **2D | 3D**（快捷键 `T`）把当前标签页的结果放进立体视图：电流分层显示（板上去程、下方地平面上的回流）；受扰地图做成电平地形并有扩散波纹；平面谐振是上下起伏的振型曲面；温度做成高度并可左右对比，加了散热器的器件上画出散热片。左键旋转、右键平移、滚轮缩放、双击复位。Three.js 内联为文本，第一次切换时才载入；不支持 WebGL 的浏览器会提示并留在 2D。3D 只是展示方式，计算和结论与 2D 完全相同。
- **结论卡片**：点卡片会在板上定位，并写明规则、建议和依据的假设。
- **假设栏**（底部）：列出阶段、网格、叠层、平面和使用了默认值的字段。

## 8. 解读导出报告

"导出报告"得到 `<名称>-verify-report.json`：

```json
{
  "tool": "layout-verifier", "stage": "P", "defaults": ["thermal", "emitters"],
  "assumptions": ["…"],
  "findings": [{ "rule": "VF-04", "sev": "P1", "title": "估计：…", "advice": "…", "assume": "…", "where": { "x": 21, "y": 18 }, "check": "PI-04" }],
  "loads": [{ "part": "U1", "loop_mm2": 1.2, "drop_mv": 0.01, "ret": "image", "corridor_mm": 1.8 }],
  "thermal": { "ta": 25, "tmax": 31.2, "p_total_w": 0.12, "parts": [{ "ref": "U1", "tj": 33.0, "tjmax": 125 }] },
  "emi": { "victims": [{ "label": "U2", "level_db": -26, "grade": "mid", "top": ["ANT1 -29"] }] }
}
```

写进评审报告时：

1. 按 `sev` 把 `findings` 并入问题列表，位置写 `where` 对应的器件或区域，"依据"一栏照抄 `assume`。
2. 阶段 P 的结论写成"布线时注意"，不要写成已确认的缺陷；阶段 R 的结论可以作为缺陷，但要注明是简化模型。
3. `defaults` 非空时，在"评审所依据的假设与缺失信息"里列出，并请用户补齐负载电流和功耗。
4. 用户改了摆放或布线后，重新导出、重新验证，对比前后的 `findings` 和 `loads`。

## 9. 局限

- 二维模型：不算介质损耗、趋肤效应、阻抗、串扰的频域特性；电磁结果是相对电平，不是场强或辐射发射。
- 阶段 P 的路径是概率估计，实际布线可能完全不同；平面缺口要手工写进 `plane_cuts`。
- 阶段 R 的网格约 0.2 mm，比 0.1 mm 更细的颈部按覆盖率折算，宽度小于一格的走线电阻会有偏差；KiCad 铺铜未填充时铜皮会缺失。
- Gerber 路线依赖 IPC-D-356 给网络标号：没有被任何焊盘或过孔记录碰到的铜块不会归到网络。
- 热模型只有板级传导和对流，不含辐射、外壳内空气流动和器件内部热阻网络。
- 结论是定性的，涉及安全或认证的判断（医疗、高压、接触温度）仍需实测。

## 10. 开发与测试

源码在 `assets/layout-verifier/src/`：

| 文件 | 内容 |
|---|---|
| `constants.js` | 铜、FR4、过孔、对流、IPC-2221、θjb 表等常数 |
| `solver.js` | 网格组装、预条件共轭梯度（聚合多重网格）、通量、本征模态、模糊、距离变换 |
| `vmodel.js` | `verify` 默认值补全、网格与掩码、引脚位置 |
| `routes.js` | 带扰动的 A* 路径集合、折线工具 |
| `current.js` / `thermal.js` / `emi.js` | 阶段 P 的电流、温度、电磁 |
| `copper.js` | 阶段 R：铜皮数据包解码、多层铜皮求解、离线检查转结论 |
| `vrules.js` / `analysis.js` | 规则表与结论；分析入口与缓存 |
| `worker.js` / `client.js` | Web Worker 与主线程回退 |
