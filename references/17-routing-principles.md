# 走线原则与检查器

布线时“先布什么、器件和线该挨多近、差分线怎么走、谁给谁让路”的原则，以及 `route_lint.py` 里对应的自动检查。几何、线宽、线长、过孔、层的量化约束见 `16-routing-constraints.md`；本文件讲的是**决策原则**，每条原则都落到可检查的规则上。

## 1. 原则总览

| 原则 | 一句话 | 规则 | 自动检查 |
|---|---|---|---|
| 优先级 | 约束越紧、越敏感的网络越先布，先占最好的位置；一般信号给它让路 | RTO-01 | `order` 给出布线顺序；`lint` 查优先级倒挂 |
| 就近 | 去耦电容贴引脚、负载电容贴晶振、ESD 贴接口、串阻贴驱动端，回流过孔贴焊盘 | RTP-01…07 | ✓ |
| 差分 | 两根线同层、并行、等距、等长，过孔成对，中间不穿别的线 | RTD-01…07 | ✓ |
| 隔离 | 攻击网络（开关节点、时钟、高速差分、高压）不与敏感网络（模拟、晶振、射频）长距离并行 | RTS-06 | ✓ |
| 短直 | 最短、拐弯最少、只用 0/45/90° | RTG、RTL-01/02、VF-19 | ✓（`16-routing-constraints.md`） |
| 回流 | 每根信号都有紧贴的回流路径；换层带地过孔，不跨分割 | RTV-02、RTS-04、RTY | ✓ 部分 |
| 一致 | 同类网络同样的出线方式、线宽、间距、方向 | RTG-07、RTS-03、RTY-02 | ✓ 部分 |
| 层分工 | 2 层板底层是地；4 层板 L2 地不走线，L1/L4 按主方向 | RTY、RTL-11 | ✓ |

自动检查的规则都进 `route_lint.py lint` 的报告，在验证器阶段 R 里显示为 VF-28…30（见第 7 节）。

## 2. 布线优先级（关键信号优先）

“信号线优先”准确地说是**关键信号优先**：最怕走长、最怕打孔、最怕被干扰的网络先布，因为它们没有退路；一般信号绕一点、打一个孔都无所谓，最后布。顺序反了，关键网络只能在别人剩下的空隙里绕行和打孔——这是 `RTO-01 优先级倒挂` 要抓的情况。

### 2.1 档位

| 档 | 类别 | 网络类 | 为什么在这一档 | 布的要点 |
|---|---|---|---|---|
| 1 | 射频与天线 | RF50 | 阻抗、长度、过孔都没有余地，位置由参考设计决定 | 照抄参考设计；最短最直、0 过孔、不分叉；135° 或圆弧拐弯 |
| 2 | 时钟源 | XTAL | 晶振线长了会起振困难、频偏、辐射 | ≤ 5 mm、0 过孔；负载电容贴晶振；下方完整地，不走其他线 |
| 3 | 开关回路与高压 | SW、HV | 热回路面积决定 EMI；高压间距决定安全 | 输入电容—开关管—地回路最小，SW 铜最小；高压先定间距和爬电 |
| 4 | 高速差分 | USB90、DIFF100 | 成对等长等距的要求最难事后补救 | 见第 4 节 |
| 5 | 单端时钟 | CLK | 边沿快、频率高，是主要的攻击网络 | 短、少过孔、完整参考平面；远离模拟和射频 |
| 6 | 模拟敏感 | ANALOG | 小信号，被耦合就是噪声 | 远离攻击网络；走在地的正上方；必要时包地 |
| 7 | 电源 | PWR_MAIN、PWR_LOW | 要宽线和通道；后布挤不出宽线 | 先干线后支路；宽线或铺铜；去耦电容就近（第 3 节） |
| 8 | 一般信号 | SIG | 低速，约束最松 | 总线成束等距；按层主方向；能绕就不打孔 |
| 9 | 地 | GND | 2/4 层板的地是平面，不是走线 | 最后铺铜、补缝合过孔，修补被切开的地 |

**同一档内**：先布最密器件（引脚最多的芯片）上的网络，因为扇出空间最紧；再按八方向最短距离从短到长。差分对两根一起布。

**电源为什么排在一般信号前面**：低功耗 IoT 板电流小，电源多半一根宽线或一块铺铜就够，但它要占通道；等一般信号把通道走满了，电源只能变细或打孔。去耦电容、DC-DC 的位置在布局阶段就定了（`07-layout.md`），布线时只是把它们连短。

**锁定**：前 4 档布好并通过检查后，写进约束文件的 `locks`，自动修复器和后续布线都不再动它们。

### 2.2 检查器

- `python scripts/route_lint.py order 板子.kicad_pcb [--json order.json]`：按上表输出推荐布线顺序（每档一张表：网络、类、焊盘数、最短长度）。Claude 落线时按这个顺序逐网走。
- **RTO-01 优先级倒挂**（P2）：前 6 档的网络如果有过孔超预算、绕行率超标或晶振线超长，检查器沿它焊盘之间的两种八方向直连走法（先斜后直、先直后斜）找挡路的铜；两种走法都被**低档位**网络的走线挡住、且不是被器件焊盘挡住时报出，并点名挡路的网络。处理办法：拆掉挡路的线，先布关键网络，再让它绕开。被器件焊盘挡住属于布局问题，不报 RTO-01，按 `16-routing-constraints.md` 第 8 节“回到布局”处理。

## 3. 就近原则

器件放在它服务的引脚旁边，连线才能短；回流过孔放在焊盘旁边，回路才能小。检查器按位号和所连网络推断器件角色（见第 8 节），测量**焊盘中心之间沿走线的路径长度**；网络有铺铜或还没连通时改用直线距离，报告里会写明是哪一种。

| 编号 | 内容 | 默认值 | 严重度 | 依据 |
|---|---|---|---|---|
| RTP-01 | 去耦电容（≤ 1 µF）到最近的芯片电源引脚 | 焊盘中心之间 ≤ 3 mm（约等于焊盘间走线 ≤ 2 mm）；拓扑为“电源 → 电容焊盘 → 引脚” | > 3 mm P2，> 6 mm P1 | [S] Nordic 评审；[E] |
| RTP-02 | 储能电容（> 1 µF） | 到芯片或电源入口 ≤ 10 mm | P3 | [E] |
| RTP-03 | 电容地焊盘到地过孔（有地平面时） | 过孔边到焊盘边 ≤ 0.5 mm | 0.5–1.5 mm P3，> 1.5 mm 或没有 P2 | [S] Nordic；[E] |
| RTP-04 | 晶振负载电容到晶振焊盘 | ≤ 3 mm | > 3 mm P2，> 6 mm P1 | [S] ST AN2867 |
| RTP-05 | ESD / TVS 到接口焊盘 | ≤ 5 mm | > 5 mm P2，> 10 mm P1 | [S] TI USB 布局指南 |
| RTP-06 | ESD 在接口到芯片的路径上、靠接口一侧 | 桩线 ≤ 1 mm；离接口比离芯片近 | P2 | [S] TI |
| RTP-07 | 串联匹配电阻靠驱动端 | 至少一端 ≤ 3 mm | 两端都 > 3 mm 时 P3（检查器不知道哪端是驱动） | [C] |

不自动检查、要人看的：去耦电容的拓扑（电源是否先经过电容焊盘再到引脚，而不是在引脚和电容之间分叉）；多个去耦电容中最小容值的那个最靠近引脚；DC-DC 输入电容与开关管、地的回路（`16-routing-constraints.md` RTL-05）；射频匹配元件贴着芯片射频引脚。

## 4. 差分线原则

差分对靠两根线之间的耦合抵消共模噪声、控制阻抗。破坏对称的任何东西——一根换层另一根不换、一根绕弯、中间穿线、间距忽宽忽窄——都会把差模转成共模，表现为辐射和眼图变差。

**识别**：约束文件的 `pairs`（`[{"p": "USB_DP", "n": "USB_DM"}]`）优先；没有时按命名配对：`_P/_N`、`+/-`、`DP/DM`、`DP/DN`、`_H/_L`，以及 `TXP/TXN`、`CLKP/CLKN` 这类。名字含 USB 的归 USB90（90 Ω），LVDS、MIPI 和其他命名成对的信号归 DIFF100（100 Ω）。命名成对但被推成普通信号的，会改成 DIFF100 并列入“需要确认”。

| 编号 | 内容 | 默认值 | 严重度 | 依据 |
|---|---|---|---|---|
| RTD-01 | 同层 | 两根线用的层相同，换层时一起换 | P1（阻抗受控的对）/ P2 | [C] |
| RTD-02 | 并行耦合 | 并行段占总长 ≥ 85%；出焊盘时分开的部分合计 ≤ 4 mm | P2 / P3 | [S] TI SPRAAR7 |
| RTD-03 | 间距一致 | 并行段的中心距偏离中位数 ≤ 10%（且 ≥ 0.03 mm 才算） | P2 / P3 | [S] TI、Microchip AN26.2 |
| RTD-04 | 对内等长 | USB90 ≤ 0.5 mm（上限 1.25 mm）；DIFF100 ≤ 0.13 mm（上限 0.5 mm）；其他 ≤ 1.0 mm（上限 2.5 mm）；补偿蛇形放在不等长发生处附近 | 超上限 P1 / 超建议 P2 | [S] Microchip AN26.2；DIFF100 为 [E] |
| RTD-05 | 过孔成对 | 两根过孔数相同、并排（对侧过孔 ≤ 1.5 mm），旁边配地过孔 | 数目不同 P1，不并排 P2 | [S] TI SPRAAR7 |
| RTD-06 | 对内不穿线 | 两根线之间不能有其他网络的铜 | P1 | [C] |
| RTD-07 | 对外间距 | 其他信号离差分对 ≥ 2 倍对内线距且 ≥ 3 倍线宽；并行 ≥ 2 mm 才报 | P3 | [S] Microchip AN26.2（≥ 3 倍） |
| — | 参考平面 | 正下方参考平面连续，不跨分割 | P0 / P1 | 验证器 VF-08、`16` RTS-04 |
| — | 阻抗 | 线宽线距由叠层计算（USB 90 Ω ±15%） | P0 / P1 | `16` RTW-07、`fab_rules.py` |

“阻抗受控的对”指 USB90 和 DIFF100；其他命名成对的信号（例如模拟差分输入）只按较低等级提醒。全速 USB（12 Mbps）对阻抗不敏感，但同层、等长、平行仍然要做。

布差分对的做法：两根一起布，先定对内线距（由阻抗算出），从两个焊盘对称出线后尽快合拢；拐弯用 45°，两根同心拐；需要等长补偿时在短的一根上、靠近不等长发生的地方加小蛇形；换层时两个过孔并排，旁边各配一个地过孔。

## 5. 隔离原则

| 编号 | 内容 | 默认值 | 严重度 |
|---|---|---|---|
| RTS-06 | 攻击网络（SW、CLK、USB90、DIFF100、HV）与敏感网络（ANALOG、XTAL、RF50）同层并行 | 边距 < max(0.5 mm, 3 倍敏感线宽) 时，并行累计 ≤ 5 mm | 5–10 mm P2，> 10 mm P1 |
| RTS-02 | 攻击网隔离距离 | ≥ max(3h, 3W)；2 层板做不到时中间加地铜和缝合过孔 | P1（人工） |

修法按代价从低到高：拉开距离 → 换层（中间隔着地平面）→ 中间加一条接地铜并打缝合过孔 → 回到布局把两类器件分区。验证器的 VF-09 用耦合比做同类检查（需要在项目里配置攻击源和敏感对象），RTS-06 不需要配置，按网络类自动找。

## 6. 其他原则

- **短直**：能直连就不绕，能少拐就少拐，只用 0/45/90°。对应 `16-routing-constraints.md` 的 RTG（几何）、RTL-01/02（绕行率）、VF-19（多余拐弯）。
- **回流**：信号的回流电流走在它正下方的参考平面上。换层时 2 mm 内配地过孔（RTV-02），不跨分割（RTS-04），2 层板底层保持完整地（RTY-03/05）。
- **一致**：同类网络用同一种出线方式（沿焊盘长轴直出，RTG-07）、同一线宽（RTW）、同一间距（成束 RTS-03）、同一方向（层主方向 RTY-02）。一致的板子好检查、好改。
- **层分工**：2 层板顶层走线、底层是地；4 层板 L2 地不走线、L3 电源、L1/L4 走线各有主方向（RTY-01…04）。

## 7. 评分 VF-28…30

在 `16-routing-constraints.md` 第 5 节的 11 项之外新增三项，总分按全部权重（122）归一化到 100：

| 编号 | 指标 | 计入的规则 | 扣分 | 权重 |
|---|---|---|---|---|
| VF-28 | 差分对 | RTD-01…07 | 有 P0 满扣；否则 0.5 × P1 数 + 0.2 × P2 数 + 0.05 × P3 数，封顶 1 | 8 |
| VF-29 | 就近 | RTP-01…07 | 同上 | 8 |
| VF-30 | 优先级与隔离 | RTO-01、RTS-06 | 同上 | 6 |

测试板 `tests/fixtures/principles-good.kicad_pcb` 得 100 分，没有任何 RTP / RTD / RTO / RTS-06 违规；`principles-bad.kicad_pcb` 每条原则各违反一次，得约 71 分并因晶振线打过孔判为不通过。这些问题属于布局和拓扑，`route_fix.py` 不会自动改，要按报告的建议挪器件或重布。

## 8. 检查器用法与局限

```bash
python scripts/route_lint.py order 板子.kicad_pcb                 # 推荐布线顺序
python scripts/route_lint.py lint  板子.kicad_pcb -o 报告.md       # 报告里包含 RTP / RTD / RTO / RTS-06
python scripts/route_lint.py constraints 板子.kicad_pcb -o c.json  # 约束文件里列出识别到的差分对（pairs）
```

实现在 `scripts/route_principles.py`。**器件角色推断**：

| 角色 | 判定 |
|---|---|
| 芯片 | 位号 U*、IC* |
| 接口 | 位号 J*、CN*、USB* |
| 去耦 / 储能电容 | 位号 C*，两个焊盘，一端接地、一端接电源网络；容值从封装的 Value 读，≤ 1 µF 算去耦，读不到按去耦处理但最高报 P2 |
| 负载电容 | 位号 C*，一端接地、一端接晶振网络；晶振是位号 Y*、X* |
| ESD 器件 | 位号 D*、TVS*、ESD*、ZD*，一端接地，另一端所在网络连到接口 |
| 串联电阻 | 位号 R*，两个焊盘，两边的网络各只连一个芯片引脚，且都不是电源或地 |

局限：

- 位号不按惯例（例如 ESD 阵列用 U*）的器件认不出来；USB ESD 阵列这类多通道器件请人工确认它在接口处。
- 去耦电容只找最近的芯片电源引脚，不判断它本该服务哪个引脚；一个引脚配多个电容时每个都按 3 mm 查，储能电容要靠容值区分。
- 差分对按命名配对，命名不规范时在约束文件 `pairs` 里写明。线距一致性只在两根同层、平行的段上采样（0.2 mm 步长）。
- 优先级倒挂只看两种八方向直连走法，不做完整的路径搜索；它说明“有更直的路被低优先级网络占了”，不保证拆掉后一定能布通。
- 阈值是工程经验值，需要用官方参考布局和人工精布的板子标定。

## 9. 出处

- TI SPRAAR7《High-Speed Interface Layout Guidelines》（差分对等长、对称过孔、回流过孔）；TI《USB 2.0 Board Design and Layout Guidelines》（ESD 靠接口、桩线）
- Microchip AN26.2（USB 差分 90 Ω、对内长度差 ≤ 1.25 mm、与其他信号间距 ≥ 3 倍）
- Nordic nRF52 DevZone 评审意见（去耦电容电流先经过电容焊盘再进芯片，地焊盘旁打过孔）
- Espressif ESP32-C3 PCB 布局指南（射频、晶振、电源走线要求）；ST AN2867（晶振与负载电容贴近芯片）
- TI SLUP432（DC-DC 热回路面积最小）
- LearnEMC（间距看到参考平面的高度 h）
