# 嘉立创EDA：从真实器件到可验证原理图

在通过 MCP、CLI 或官方 API 新建、整理、标准化嘉立创EDA原理图时使用。具体命令、枚举和能力以现场工具版本为准；本文规定检查方法，不绑定某一版接口。

## 先建立四份依据

1. **需求和电源域表**：电池范围、工作方式、各芯片 VDD/VDDIO、接口电平、断电状态、烧录参考电压、页面数量与纸张。沿用已确认的选择，不反复询问。
2. **器件表**：位号、完整 MPN（含后缀）、制造商、供应商料号、数值/精度/额定值、符号、封装、BOM/PCB 标志、默认装配状态。库中有结果不等于型号正确，商城库存也不等于 PCBA 库存。
3. **连接表**：以 `位号:物理引脚号 → 网名 / 明确 NC` 为基本单位。记录每个电源脚、地脚、EP、连接器外壳脚；未知状态不能当作 NC。器件引脚的外设复用限制单独核对。
4. **资料索引**：主要芯片及关键连接器、天线的原厂手册、封装图和参考设计存入项目 `docs/datasheets/`、`docs/reference-designs/`。索引至少记录完整型号、原始 URL、下载日期、版本、关键页码和 SHA-256。提取文本只用于检索，封装和原理图仍需看原始页面。

原厂文件优先；使用商城托管的原厂 PDF 时记录来源。下载后确认是有效 PDF，检查型号与修订。不要把 HTML 错误页保存成 PDF，也不要未经授权把整套第三方手册发布到公共经验仓库。

## 一次画对的顺序

**先定器件和封装，再量符号，再排版，再连线。** 使用占位电阻替代电感、只改显示名称、最后再补封装，会把库身份错误和尺寸变化带到最后。

1. 确认正在操作的应用窗口、工程 UUID、页面 UUID 和宿主版本。只读快照、原生工程备份、原始网表先落盘。
2. 核对手册、封装编号与 pin/pad 映射；保留可采购的真实器件身份。RF 匹配件保留参考设计要求的封装与介质，不能为方便装配任意放大。
3. 从真实符号读取引脚位置、朝向和可见文字范围，按功能分区安排 A4。预留图签、烧录口、天线和注释位置；先试排密度最高的一页。
4. 同页核心与去耦、反馈、晶体、匹配等外围用实际导线表达拓扑。电源用标准 VCC/电源旗，地用标准 GND 符号；接口和跨页信号再用标号或端口。
5. 先完成一个小模块的放置、连线、保存、重载、回读和导图，验证工具语义后再批量操作。
6. 每批修改后比较逐脚连接和几何。最终全工程检查网表、身份、NC、BOM、图面和原生 DRC；保存并重载全部页面后再导出交付版本。

用户要求固定页数时，先缩短冗余桩线、压缩功能区间距、重新分配功能区。不要靠缩小字号，或把注释塞进图签实现“入框”。

## 替换器件要同时守住身份和连接

- 替换前在临时位置放置候选，核对 MPN、供应商编码、封装、完整引脚号和功能。新旧符号可能引脚 1/2 对调、旋转不同、引脚间距不同，不能只比较引脚数量。
- 同功能无极性两端器件可以调整符号方向，但仍保持原来的物理引脚号到网络映射，减少后续 PCB 更新意外。多脚 IC 按逐脚表匹配，不能按视觉位置猜映射。
- 有事务式替换接口时优先使用；需要显式删除旧实例时，先验证候选和重新布线计划，保留完整备份。不能删除原件后才发现新封装不可读。
- “原库身份不明”与“换成确定的新器件”是两种情况。后者可以是有依据的标准化，但不能声称已证明旧器件本来就是该型号。
- 自建符号只修正已证实的错误，不覆盖公共库。把新符号绑定到已核对的封装，再放置验证。库级创建成功不等于可放置、可连线或可制造。
- 位号、唯一 ID、NC、BOM/PCB 标志和默认贴装状态都要回读。DNP 不是 NC：DNP 器件仍保留焊盘和电路连接，装配文件必须明确排除。

## 数据格式和失败恢复

- 区分器件库 UUID、实例 UUID、符号 UUID、封装 UUID。不要把图中实例 ID 当作库器件 ID 使用。
- 区分原理图 raw 坐标、毫米和 PCB mil，以及 y 轴方向、器件原点和引脚连接点。
- **原生线段数组不一定是连续折线。** 若一个导线记录包含多个独立的端点对，必须按该格式逐段解码；将所有数字直接传给 polyline 会凭空增加斜线和短路。修改前先离线验证正交、首段出脚方向、非目标引脚穿越和异网交叉。
- 网络端口的属性坐标和实际电气连接点可能不同。按引脚回读对齐，不能用图形中心落线。更换电源符号后再比较所有受影响的 pin-net 对。
- 连续调用同一 EDA 窗口的写操作；不要让多个流程并发切页。读导出可以独立处理，但必须避免打断正在执行的页面事务。
- 超时、`partial`、FIFO/页面变更或 stale ID 后，先保存已知证据并读取实际库存。确认哪些步骤已落地，再生成剩余修复；不要原样重放整批动作，也不要仅因 CLI 返回成功就宣布完成。
- 保留源数据与原始观测。不能修改快照、日志或导出图来掩盖不一致。若写入能力不支持必要操作，明确未完成项并保留可恢复工程。
- **交叉不等于连接。** 两条导线在中段相交，可能没有电气连接；共线中间点还可能被宿主合并。公共支路优先使用明确的 T 形端点连接，并回读所有参与引脚的网络。不能靠“坐标相等”推断四向交点已经接通。
- 移动器件组后，除坐标和连接外，还要核对完整型号、供应商编号、Value、容差、功率、封装和 BOM/PCB 标志。本次在特定宿主/连接器组合中发现移动后部分自定义属性为空；这属于需要回读捕获的实例问题，不能认为所有版本都如此。
- 将可读性标注与供应商标准属性分开。保留库中 Name 的属性引用和真实 Value；额外的阻抗说明、接口用途、装配备注用可见说明文字表达。若自行改名导致标准化告警，应核实是显示差异还是型号/参数错误，不能直接忽略整组告警。
- 宿主弹窗可能提出全工程库替换并清除撤销历史，这与仅替换一个实例的影响范围不同。先做本地备份；若无需全局更新即可完成任务，保留现有工程库并使用已核验的局部实例替换。本次采用此方式完成了局部标准化。

## 电源与地的画法

标准符号的**外观**和网络的**电气名称**分别核对。例如 VCC 旗可以标为 `3V3`、`1V8`、`3V3_TF`、`VBAT`，但同一电源全工程必须使用一个确切名字。改外观时不应顺便把所有电源统一成 `VCC`，否则会短接不同电压域。

电源尽量向上、地向下。密集 IC 引脚先汇集同网支路再放符号，避免每个脚一个旗造成重叠。没有独立模拟地设计时继续使用同一个 `GND`；不要为了图面好看虚构 AGND/PGND 分割。保护地符号只用于真实保护接地。

## 低压域与间歇存储

连续采样、RAM 缓存、间歇写卡时，分别计算传感器、RAM、MCU、无线、TF 写入和电源损耗的平均能量。1.8 V 的收益取决于各负载电流随电压的变化及转换效率，不能直接把整机功耗乘以 `1.8/3.3`。

核对 RAM 的完整电压后缀。3.3 V PSRAM 通常不能直接迁移到 1.8 V。TF 保持其允许的电压；模拟开关只提供隔离，不能代替电平转换。共享 SPI 还要保证未选中器件和转换器的 MISO 高阻。VTref 跟随目标 MCU 的 I/O 电压，不能固定接另一电源域。

## 射频分层审查

SoC ANT 脚 → 原厂匹配/谐波滤波 → **50 Ω 参考点** → 天线选择/馈线 → 天线匹配 → 天线，是不同设计环节。SoC ANT 脚本身不一定是 50 Ω，不能给前段套一条通用 50 Ω 走线规则，也不能把芯片匹配网络误当作天线最终匹配。

外置同轴接口便于调整天线位置和传导测试；陶瓷天线体积小，但地平面、净空、外壳、电池和人体也是天线系统的一部分。比较的是最终整机效率和链路余量，不是手册中脱离测试板条件的峰值增益。

双天线选项用互斥装配的串联元件或合适 RF 开关，不能直接并联。串联选择件紧贴分叉，未选通支路不得留下长悬空 stub。预留匹配元件并明确 DNP；手册评估板上的值只作起点。网络分析仪校准到馈点，实测 S11 后再测效率、方向图、吞吐/丢包与距离；较好的 S11 不能单独证明较高辐射效率。

## 验收与复盘

交付时分别说明：逐脚网表结果、器件身份/封装检查、图面可读性、DRC、未完成电气问题、尚未覆盖的 PCB/射频实测。工程可保存、DRC 可通过，都不能替代实物验证。

复盘记录“现象 → 根因证据 → 修复 → 下次前置检查”。优先沉淀可复用的数据格式、身份验证和恢复方法；不把偶然的宿主错误写成所有版本都存在的规律，也不把一块板的器件值固化成通用设计。

## 下一次从零开始的最短可靠路径

1. 先固定电源域、总线电压、工作负载、存储方式、调试接口和天线装配选项；不急着摆图。
2. 建立器件及资料清单，核对完整型号后缀、实物封装、时钟专用脚和引脚表。供应商库存只作为带日期的快照。
3. 小批放入真实器件，读取引脚和几何；在本地连接表中确定逐脚网络和 NC，再规划五页或其他既定页数的功能分区。
4. 每个模块完成“连接—逐脚核验—图面检查—保存”后再复制模式。先把最复杂的 MCU、RF、电源模块做对，再整理重复去耦和上拉。
5. 最后执行全工程保存、重载、网表差异检查、原生 DRC 和导图复核。区分完成的原理图工作与尚待 PCB、固件或实测解决的问题。

参考例证：Nordic 的 [clock pins 约束](https://docs.nordicsemi.com/r/bundle/ps_nrf54l15/page/chapters/pin.html-clock_pins) 与 [QFAA 引脚表](https://docs.nordicsemi.com/r/bundle/ps_nrf54l15/page/chapters/pin.html-qfn48) 应一起核对；Johanson 的 [2450AT18D0100001E 手册](https://www.johansontechnology.com/datasheets/2450AT18D0100001E/2450AT18D0100001E.pdf) 同时包含器件尺寸、引脚、板级净空和评估板条件，不能只摘录天线体积或增益。
