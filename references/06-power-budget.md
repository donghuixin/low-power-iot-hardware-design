# 功耗预算：静态电流、峰值电流与续航

功耗预算在阶段一就要做第一版，原理图完成后逐器件核对，板子回来后用实测替换估算。预算不闭合时改架构，不要寄希望于固件优化。

## 1. 模型

低功耗设备的电流波形是"极低的基线 + 稀疏的尖峰"：

```
I平均 = I睡眠 + Σ ( I事件i × t事件i × 每周期次数i ) / T周期
续航 = 电池容量 × 可用系数 / I平均
```

三个量各自决定不同的事：
- **睡眠电流**（µA 级）：占空比很低时，它决定续航。
- **事件电荷**（每次唤醒消耗的 µC / mC）：占空比高时，它决定续航。
- **峰值电流**（mA 级）：不直接决定续航，但决定电池、稳压器和储能电容是否带得动。

先算哪一项占主导，再针对它优化。运行 `scripts/power_budget.py` 得到各项占比。

**扩展模块**：持续功耗 >1 W 等进入条件成立时（见 SKILL.md），本模型不适用，改用 `22-low-noise-power-thermal.md` 的持续功耗-热模型。

## 2. 睡眠电流：逐项清点

睡眠电流是所有常开路径的总和。原理图审查时，对每个器件和每个电阻都问一句"睡眠时它耗多少电"。

| 来源 | 典型量级 | 说明 |
|---|---|---|
| MCU/SoC 睡眠 | 0.3–5 µA | 取决于模式：是否保留 RAM、是否运行低频时钟/RTC、哪些唤醒源使能。查手册中与实际配置一致的那一行 |
| 稳压器静态电流 Iq | 几十 nA 到几十 µA | 每一级都算；包括 SoC 内置稳压器 |
| 传感器待机/低功耗模式 | 0.1–10 µA 每个 | 上电默认可能不是最低功耗模式，需固件显式配置；运动唤醒等常开功能的电流另计 |
| 外置 Flash | 待机 10–50 µA；深度掉电 0.1–2 µA | 必须由固件发命令进入深度掉电 |
| 电平转换器、逻辑器件、模拟开关 | 0.1–10 µA | — |
| 运放、比较器、基准源 | 几百 nA 到数百 µA | 常开的模拟前端要选纳安级器件或做电源开关 |
| 负载开关、电池保护芯片、充电芯片、电量计 | 0.01–50 µA | 充电芯片无输入时的电池侧电流；电量计休眠电流 |
| **恒定导通的电阻路径** | 可达数百 µA | 常态被拉向相反电平的上下拉；电池分压器（3 V / 2 MΩ = 1.5 µA，3 V / 200 kΩ = 15 µA）；NTC 偏置；LED |
| **悬空输入的贯通电流** | 几十到几百 µA，不稳定 | 包括连接到已断电外设的输入引脚 |
| **断电域反灌** | 几十 µA 到 mA | 见 `04-schematic-signals.md` 第 5 节 |
| 电容漏电 | MLCC 很小；钽/电解/超级电容可达 µA 级 | 储能大电容要查漏电规格 |
| TVS、二极管反向漏电 | nA 到 µA，高温显著增大 | 肖特基漏电尤其大 |
| PCB 表面漏电 | 通常可忽略；潮湿和助焊剂残留时可达 µA | 高阻节点受影响 |
| 电池自放电 | 等效 µA 级（锂锰约每年 1%，锂离子每月 1–3%） | 多年续航的设计必须计入 |

注意温度：漏电流大致每升高 10 °C 翻一倍。手册的典型值多为 25 °C，高温环境按最大值或高温曲线估算。

**输出格式**：睡眠电流逐项表，列出器件、电流、依据（手册页或假设）、合计，与目标对比。

## 3. 事件能耗

对每类周期性活动估算电流曲线：

| 事件 | 需要的数据 |
|---|---|
| 唤醒与时钟启动 | 高频晶体启动时间（约 0.3–1.5 ms）内的电流；从深度睡眠冷启动的时间 |
| 传感器采样 | 上电稳定时间 + 转换时间 × 工作电流；连续模式 vs 单次模式 |
| 处理 | CPU 运行电流 × 时间（µA/MHz × 频率） |
| 射频 | 发射/接收电流 × 空中时间；BLE 一次广播或连接事件可用厂商的在线功耗估算工具或实测曲线 |
| 存储 | Flash 写入/擦除电流（几到几十 mA）× 时间（擦除可达几十到几百 ms） |
| 指示 | LED、蜂鸣、振动的电流 × 时间 |

降低事件能耗的硬件手段：更高的数据速率（缩短空中时间）、传感器 FIFO 批量读取（减少唤醒次数）、启用片内 DCDC、选启动快的晶体和传感器、提高 SPI/I2C 速率。

## 4. 峰值电流

### 清点
列出所有大电流事件及其是否可能同时发生：

| 负载 | 峰值量级 |
|---|---|
| BLE / 802.15.4 发射 | 5–20 mA |
| LoRa 发射 | 30–130 mA |
| WiFi 发射 | 200–400 mA |
| 蜂窝发射 | 200–500 mA，2G 可达 2 A |
| GNSS 捕获 | 20–50 mA，持续数秒到数十秒 |
| Flash 擦写 | 5–25 mA |
| 振动马达 / 蜂鸣器 | 50–150 mA，启动更高 |
| PPG LED / 红外发射 | 几十到 200 mA 脉冲 |
| 显示背光、电子墨水屏刷新 | 几到几十 mA |
| 被开关电源域的浪涌 | 取决于电容量与开关速度，可达数百 mA |
| MCU 全速运行 | 几 mA |

固件可以错开峰值（例如不在射频发射期间擦 Flash、马达振动时不发射），把这类约束写进给固件的说明里。

### 压降核算
```
V最低 = V电池(末期开路电压) − I峰值 × (R电池内阻(末期/低温) + R路径)
```
R路径包括保护 MOSFET、PTC、负载开关导通电阻、连接器接触电阻、走线电阻。要求 V最低 高于：稳压器最低输入电压（含压差）、SoC 欠压复位阈值、各器件最低工作电压，并留余量。

升压拓扑下，电池侧电流 = 输出电流 × Vout / (Vin × 效率)，电池电压越低，电池侧电流越大，形成恶性循环，要按最低电池电压核算。

不满足时的选择：加储能电容（`05-power-architecture.md` 第 7 节）、降低发射功率、换内阻更低的电池、错开峰值、减慢被开关域的上电速度。

### 稳压器能力
每一路稳压器的最大输出电流 ≥ 该路峰值电流并留余量；开关稳压器的电感饱和电流高于峰值电感电流；负载瞬态响应（从 µA 跳到几十 mA）造成的输出跌落在可接受范围，输出电容足够。

## 5. 续航估算

```
可用容量 = 标称容量 × 可用系数 − 使用期内自放电
续航(小时) = 可用容量(mAh) / I平均(mA)
```

- 稳压器之后的负载电流要折算到电池侧：LDO 为 I电池 = I负载 + Iq；开关稳压器为 I电池 = I负载 × Vout / (Vin × η) + Iq，其中 η 用对应负载电流下的效率（睡眠时用轻载效率，不能用标称的 90%）。
- 可用系数通常取 0.7–0.85，脉冲负载下的纽扣电池取更低。
- 给出估算时写明假设，并给出乐观/保守两个值而不是一个精确数字。

## 6. 实测

估算必须用实测校验，硬件上要为此留条件（见 `08-bringup-production.md`）：

- 用能测 nA 到百 mA 动态范围并带时间波形的仪器（功耗分析仪、源测量单元），普通万用表的采样率和量程切换会漏掉脉冲并引入负担电压。
- 测量时断开调试器，拔掉串口线；调试接口保持连接会使 SoC 的调试域保持供电，睡眠电流虚高。
- 先测"空固件"的最低睡眠电流，确认硬件基线与预算一致，再逐个启用外设，定位每一项的贡献。
- 睡眠电流高于预算时的排查顺序见 `08-bringup-production.md`。

## 7. 预算不闭合时的调整方向

按效果从大到小：
1. 降低占空比（上报间隔、采样率、连接间隔）。
2. 找出并消除漏电路径（通常是最大的意外来源）。
3. 减少稳压级数或换低 Iq 器件；降低系统电压。
4. 对待机电流大的外设做电源开关。
5. 本地处理后少传数据。
6. 换电池（容量或化学体系）。
7. 重新选无线方案。
