# 布线指导思想与工作方法

合格的硬件工程师不是“拿到原理图就开始连线”。他边读懂电路，边查资料核实，边想清楚每一块电路的电流怎么流、哪些网络最怕什么，边落笔设计；每一块布完马上检查，发现冲突就回到布局。本文件规定 Claude 做 Layout 时的**工作方法**和**指导思想**，后者综合了 ADI AN-1142《高速 ADC PCB 布局布线技巧》和 TI ZHCAAE6B（SLVA959）《电机驱动器电路板布局的最佳实践》，并落到 `16-routing-constraints.md`、`17-routing-principles.md` 的可检查规则上。

## 1. 工作方法：理解、查证、思考、设计交替进行

不要先把整板读完、查完、想完再动手，也不要不读不查就连线。按**功能块**推进，每一块走一遍下面的循环，块与块之间按 `17-routing-principles.md` 第 2 节的优先级排序（射频 → 晶振 → 开关回路与高压 → 高速差分 → 时钟 → 模拟 → 电源 → 一般信号 → 地）。

```
  ┌──────────────── 下一个功能块（按优先级）────────────────┐
  │                                                          │
  ▼                                                          │
① 读懂这一块 → ② 查证 → ③ 定约束和走法 → ④ 布这一块 → ⑤ 立即检查 ─┘
       ▲                                         │
       └──────── 发现冲突：回到布局或回到 ① ───────┘
```

**① 读懂这一块**。不看走线，先看电流：

- 这一块的功能是什么，接在谁和谁之间；
- **大电流环路**在哪里（输入电容 → 开关管 → 电感 → 输出电容 → 地；电源正 → 上管 → 负载 → 下管 → 电源负）；
- **高 dv/dt 节点**（开关节点、自举、时钟、PWM）和 **高 di/dt 路径**——它们是攻击源；
- **敏感节点**（ADC 输入、基准、晶振、射频、电流检测、高阻节点）——它们是受害者；
- 每条信号的**回流路径**走在哪一层、经过哪里，换层时回流怎么跟过去；
- 哪些连接是开尔文连接（电流检测、电压反馈要从被测点单独引出）。

把结论写成一两行：例如“DC-DC：热回路 C3–U4.VIN–U4.PGND，SW 节点 U4.SW–L2，反馈从 C7 正端开尔文引出，FB 走线远离 SW”。

**② 查证**。能查数据手册就不凭记忆：芯片 datasheet 的 Layout 章节、评估板的 Gerber 与参考布局、厂商应用笔记（射频、晶振、DC-DC、USB 的要求以厂商为准）。

- **需要联网检索、下载手册、打开用户电脑上的文件或项目目录时，先征得用户同意**，说清楚要查什么、为什么；用户不同意或连不上时，按本 skill 的典型值做，并在结论里标“未核实”。
- 查到的资料按 SKILL.md“设计资料管理”保存，记录型号、版本、来源；网页摘要不能代替封装图和引脚表。
- 资料之间有冲突（例如两份应用笔记对地分割的说法不同）时，写明采用哪一条、为什么（见第 3 节）。

**③ 定约束和走法**。给这一块的每个网络定网络类和档位（`route_lint.py constraints` 生成后人工确认），写下：哪条环路要最小、哪几根要成对等长、哪根不许打孔、走哪一层、从哪个方向出焊盘、换层点在哪。说不出“为什么这样走”的线，先别画。

**④ 布这一块**。先布环路和关键网络，再布其余；线段坐标按八方向构造（第 2.6 节），写入 EDA 前过 `route_lint.py gate --brief design-brief.json`（G0–G4 未放行会被拒绝，见 `19-design-gate.md`）；这一块布完截图发给用户看过再进入下一块。

**⑤ 立即检查**。这一块布完就跑 `route_lint.py lint`，看本块网络有没有新的违规；关键网络通过后写进约束文件的 `locks`。出现优先级倒挂、绕行率超标、关键网络要打孔才能连通时，**回到布局**，不要硬绕。

**什么时候问用户**：要联网、下载、读用户文件之前；电路功能看不懂、网络用途有两种解释时；需要改布局（挪器件、换封装、加层）时；需要在两份资料的冲突里二选一、而这个选择影响成本或性能时。

## 2. 指导思想

### 2.1 电流走环路，先找回路再画线

每一条电流都要回到源头。布线首先是**把环路做小**：热回路面积最小、开关节点铜皮短而宽、大电流路径元件靠近、尽量不换层，换层就打足够多的过孔（TI）。信号也一样：回流在参考平面上紧贴信号走，所以信号下方的地不能被切断。

### 2.2 地：单一完整地 + 分区布局，不盲目分割

- 2 层以上的板子用**完整的地平面**；2 层板底层整层铺地（TI；本 skill RTY-03）。
- **不盲目把 AGND 和 DGND 分开**：分割会拉长回流路径、增大电感，V = L·di/dt 让噪声变大（ADI）。用**分区布局**把数字、模拟、大功率电路放在各自区域，让回流电流自然留在本区（ADI、TI 都这样说）。
- 必须分开的地（例如电机驱动的功率地与逻辑地）只在**一个星点**连接，连接点放在转换器或驱动器、分流电阻附近（ADI、TI）。
- 返回路径宽、短、低阻抗；走线、过孔排、连接器不要把地平面割裂成窄条（TI）。地平面被切碎由 RTY-05 / VF-21 检查。

### 2.3 去耦：选对、放近、过孔放对位置

- **不堆砌电容**：选对容值和类型，0.1 µF + 10 µF 两种往往就够；多种电容并联可能互相谐振反而变差（ADI）。
- **小电容最靠近引脚，大电容在外侧**（TI）；电源入口和芯片 VDD 引脚处去耦总是有益的（ADI）。
- **电容与芯片在同一层，之间不打过孔**；过孔打在电容焊盘外侧，“电源平面 → 过孔 → 电容焊盘 → 引脚”；电容离芯片 < 5 mm，连线长宽比 ≤ 3:1，线尽量宽、过孔尽量多（TI）。
- 多层板让电源层与地层紧贴（≤ 4 mil），白得的平面电容负责几百 MHz 以上的去耦（ADI）。

### 2.4 层间耦合：敏感层不要挨着噪声层

即使相隔 40 mil，信号也会电容耦合到相邻层：1 V 的数字开关在相邻敏感层耦合出约 1 mV，对 12 位、2 Vp-p 的 ADC 就是约 2 LSB（ADI）。敏感走线所在层与噪声层之间要隔一层地；查到无法解释的杂散，先查相邻层。

### 2.5 裸露焊盘：电气、散热、焊接三件事

- 裸露焊盘（ADI 称“引脚 0”）是芯片内部所有地的汇集点，也是主散热路径，必须可靠连到地平面（ADI、TI）。
- 焊盘下打**过孔阵列**，每一小块一个过孔；能在其他层复制焊盘就复制；用阻焊或丝印格栅把大焊盘分成小块，避免回流焊时焊膏跑偏；过孔塞孔，防止焊料流进孔里（ADI）。
- 散热过孔直接连到各层铜，不用热焊盘（花焊盘）连接，不盖阻焊；下方大面积连续覆铜（TI）。
- 过孔数量由 RTV-08 检查。

### 2.6 走线几何：只用 135° 拐角，禁止直角和随机角度

- 线段只走 0/45/90/135° 四个方向，**拐角只允许 135°（每次转向 45°）**；**直角拐角一律不接受**（所有网络类，含电源和地线），锐角一律禁止（TI：用 45° 或圆弧减少阻抗突变和 EMI；本 skill RTG-01/02/04，直角为 P0）。需要转 90° 时，用两个 135° 拐角，中间斜段 ≥ max(2w, 0.2 mm)。
- **绝不出现随机角度的折线**：线段坐标必须由八方向构造算出——从焊盘沿长轴直出，再用 (±d, 0)、(0, ±d)、(±d, ±d) 的位移拐向目标；不要把两端焊盘直接连成一条斜线（`16-routing-constraints.md` 第 8 节）。
- 圆弧只用于射频、柔性弯折区、高压区，且要声明豁免区。
- 过孔与焊盘的连接处可加泪滴，减轻热应力、提高可靠性（TI；RTG-11）。

### 2.7 大电流与功率级

- 大电流线宽而短；栅极驱动线宽而短（1 oz 铜约 20 mil 起），上管栅极线与开关节点线**紧贴并行**，回路面积最小（TI）。
- 换层用多个过孔，靠近电流进出的引脚。过孔载流（1 oz、温升 10 °C、IPC-2152，TI 表）：孔径 6 mil ≈ 0.2 A，8 mil ≈ 0.55 A，10 mil ≈ 0.81 A，12 mil（0.3 mm）≈ 0.84 A，16 mil ≈ 1.1 A。
- 铜厚加倍，同面积平面热阻约减半（TI）。

### 2.8 敏感测量：开尔文连接与差分走线

- 电流检测、电压反馈、漏极电压检测从被测点**单独引出**（开尔文连接），不与功率铜共用；用 net-tie 标记分流电阻两端，防止布线时误接（TI）。
- 检测信号成对平行、从分流电阻直达放大器；输入滤波器（如 1 kΩ + 100 pF）贴近放大器；检测线不与开关噪声线平行（TI；本 skill RTD、RTS-06）。
- 源端匹配电阻、交流耦合电容等成对无源器件并排、对称放置（TI）。

### 2.9 耦合规律

电容耦合比电感耦合更常见：平行越长、dv/dt 越快、间距越近，耦合越重。噪声线远离敏感线，并走在地平面正上方（TI；本 skill RTS-06、RTD-07）。

## 3. 两份应用笔记的要点与取舍

| 主题 | ADI AN-1142（高速 ADC） | TI ZHCAAE6B（电机驱动） | 本 skill 的取舍 |
|---|---|---|---|
| 地分割 | 一般不分割；靠分区；必须分时单点桥接，放在转换器附近 | 分区布局，不是物理分开数字地和模拟地；功率地与逻辑地物理隔离、星点单点相连 | 默认单一完整地 + 分区；只有大电流功率地与逻辑地分开，星点相连（RTY-06 提醒确认） |
| 去耦 | 不堆砌；0.1 µF + 10 µF；平面电容管高频 | 小电容靠近、大电容在外；电容与芯片间不打过孔；< 5 mm；长宽比 ≤ 3:1 | 两者都采纳（RTP-01、RTP-03、RTP-08） |
| 裸露焊盘 | 过孔阵列、多层复制、分割焊盘、塞孔 | 散热过孔直连、不加热焊盘、不盖阻焊；20/8 mil 阵列 | 都采纳（RTV-08） |
| 拐角 | 未涉及 | 避免 90°，用 45° 或圆弧 | 线段只走八方向，拐角只用 135°；直角（P0）、锐角和任意角度一律禁止（RTG） |
| 层间 | 敏感层不挨噪声层 | 噪声线走在地平面上方 | 采纳（人工检查；RTS-06 查同层） |
| 测量 | — | 开尔文、net-tie、差分直达、滤波器靠近放大器 | 采纳（RTD、RTS-06；开尔文人工检查） |

两份笔记针对的场景不同：ADI 关注的是高速 ADC 的噪声和去耦，TI 关注的是大电流、高 dv/dt 的功率级。低功耗 IoT 板两种场景都可能有（DC-DC 与 ADC 共板），按上表取用。

## 4. 落到检查器的规则

| 指导思想 | 规则 | 检查器 |
|---|---|---|
| 45° 优先、禁随机角度和锐角 | RTG-01、RTG-02、RTG-03、RTG-04 | `route_lint.py lint` / `gate`，`route_fix.py` 自动修 |
| 布线优先级、关键网络不被挡路 | RTO-01 | `route_lint.py order` / `lint` |
| 去耦电容近、同层、之间不打孔，地焊盘旁有过孔 | RTP-01、RTP-03、RTP-08 | `lint` |
| 裸露焊盘过孔阵列 | RTV-08 | `lint` |
| 单一完整地、地不被切碎 | RTY-04、RTY-05、RTY-06 | `lint` |
| 换层带地过孔 | RTV-02 | `lint`（4 层以上） |
| 攻击与敏感网络不并行 | RTS-06 | `lint` |
| 差分与检测线成对、等长、等距 | RTD-01…07 | `lint` |
| 热回路最小、开尔文连接、层间耦合、泪滴 | RTL-05、RTG-11 | 人工检查，按本文件第 2 节 |
