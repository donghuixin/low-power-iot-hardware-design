# 出图前检查：丝印、位号编号与泪滴（G5）

布线定稿以后、导出 Gerber 之前，必须过 G5。这一步解决的是“板子印出来、贴出来认不认得，连得牢不牢”：
丝印压焊盘被板厂裁掉、位号放在两个器件中间、二极管没有阴极标记、两个 C5、R? 没编号、细线进大焊盘没泪滴——
这些问题 DRC 都查不出来，到了贴片厂和维修台上才暴露。

## 1. 流程

1. `python scripts/design_gate.py ask design-brief.json G5`：列出还没回答的问题，每项带选项、推荐值和“为什么要问”。
2. **原样发给用户**，可以分三次问：丝印（13 项）→ 位号编号（2 项）→ 泪滴（3 项），最后是丝印截图和极性核对。
   用户说“按推荐”“都按推荐”才能填推荐值；用户没回答的项保持待填。不能替用户选，也不能“先按推荐填上，用户有意见再改”。
3. 用户回答后写进 `G5_finish`（命令行直接编辑 JSON；扩展里用“丝印”页或 MCP `design_brief_update`）。
4. 在 EDA 里按决定改丝印、重新编号并反标、执行泪滴并重新铺铜。
5. `python scripts/finish_lint.py 板子.kicad_pcb --brief design-brief.json [--bom bom.csv] --json finish-lint.json -o 出图前检查.md`，
   或者在扩展“丝印”页点“检查并记录”。
6. P0 必须改。P1 逐条改掉，或者把用户同意保留的写进 `G5_finish.accepted_exceptions: [{rule, refs, why}]`（`why` 必须写）。
   P2 / P3 列给用户看，改不改由用户决定。
7. 请用户只开顶层丝印 + 焊盘（或 3D 预览）截图看一遍，并对照原理图逐个核对极性器件，然后 `summary G5` 发确认码。

报告里记着 `rules_hash`：只要改了会影响检查结果的决定（工艺、字高、位号策略、方向、标注、编号方式、泪滴策略……），旧报告就作废，要重新检查。
改截图文件名、泪滴执行记录、反标记录或保留问题，不会让报告作废。

## 2. 20 个引导问题

| # | 字段 `G5_finish.` | 问题 | 选项 / 格式 | 推荐 |
|---|---|---|---|---|
| 1 | `silk.process` | 丝印工艺 | 标准丝印 / 高精度丝印 / 镂空字 | 标准丝印 |
| 2 | `silk.text_height_mm` | 字高 | 数字 | 1.0 |
| 3 | `silk.line_width_mm` | 文字线宽 | 数字 | 0.153 |
| 4 | `silk.pad_clearance_mm` | 丝印离焊盘 | 数字，≥ 0.15 | 0.2 |
| 5 | `silk.designators` | 位号怎么印 | 全部显示 / 只印关键器件 / 不印（用装配图） | 全部显示 |
| 6 | `silk.orientation` | 文字方向 | 0° 和 90° / 全部 0° | 0° 和 90° |
| 7 | `silk.polarity` | 极性与 1 脚标记方式 | 自由描述 | 芯片 1 脚圆点、二极管阴极横杠、极性电容 +、接口 1 脚三角 |
| 8 | `silk.labels` | 接口、按键、灯、测试点的说明 | `[{ref, text}]` 或“无” | J1 USB、SW1 RST… |
| 9 | `silk.board_marking` | 板名、版本 | `{name, version}` | — |
| 10 | `silk.warnings` | 警示标注 | 文字列表或“无” | 无 |
| 11 | `silk.compliance` | 认证 / 回收标志 | 自由描述或“无” | 无 |
| 12 | `silk.jlc_order_no` | 嘉立创订单号位置 | 板厂默认位置 / 指定位置 / 不加 | 指定位置 |
| 13 | `silk.bottom_silk` | 底面丝印 | 需要 / 不需要 | 需要 |
| 14 | `annotation.scheme` | 编号方式 | 按位置重新编号 / 按原理图顺序 / 保持现状 | 按位置重新编号 |
| 15 | `annotation.back_annotated` | 已反标回原理图、重新导出 BOM 和坐标 | 是 / 没有改动 | 是 |
| 16 | `teardrops.policy` | 泪滴策略 | 全部焊盘与过孔 / 仅过孔和插件孔 / 不加 | 全部焊盘与过孔 |
| 17 | `teardrops.exclude_rf_diff` | 射频和差分线去掉泪滴 | 去掉 / 保留 | 去掉 |
| 18 | `teardrops.done` | 泪滴执行记录 | 已执行并重新铺铜 / 不加泪滴 | 已执行并重新铺铜 |
| 19 | `silk.review.screenshot` | 用户看过的丝印截图 | 文件名 | — |
| 20 | `silk.review.polarity_checked` | 已对照原理图核对极性和 1 脚 | 已核对 | 已核对 |

另有可选的 `annotation.bom`：BOM 文件路径，给了就用 `--bom` 核对位号。

问的时候要把“为什么”一起说，用户才会认真回答。几个容易被跳过、但值得多说一句的：

- **离焊盘距离**：板厂会把压到焊盘和过孔上的丝印自动裁掉，所以不会印到焊盘上，代价是字变残。看起来“DRC 没报错”，印出来却缺笔画。
- **只印关键器件**：板子很挤时，这比把字缩到 0.6 mm 好得多；阻容的位号靠装配图（坐标文件 + 丝印图）找。
- **订单号**：默认位置可能落在外壳开窗、导光柱或标签位置下面；指定位置就是在想放的地方放一行 `JLCJLCJLCJLC`。是否要加价以下单页为准。
- **编号方式**：按位置重新编号后必须反标回原理图，否则 BOM、坐标文件和板子对不上，贴片厂会按错的 BOM 贴料。
- **泪滴策略**：细线（≤ 0.2 mm）进大焊盘、插件孔和过孔最需要泪滴；射频 50 Ω 和差分线一般不加，避免阻抗突变。

## 3. 嘉立创丝印工艺下限

| 工艺 | 最小线宽 | 最小字高 | 备注 |
|---|---|---|---|
| 标准丝印 | 0.153 mm（6 mil） | 1.0 mm | 字高与线宽约 6:1 最清楚；KiCad 默认 0.15 mm 视为满足 |
| 高精度丝印 | 0.1 mm | 0.8 mm | 看板厂和板材是否支持、是否加价 |
| 镂空字 | 0.2 mm | 1.5 mm | 白底镂空的字要更粗更大 |

丝印离焊盘 ≥ 0.15 mm，建议 0.2–0.25 mm。数值以下单时板厂工艺页为准，变化时更新本表和 `finish_lint.py` 的 `PROCESS`。

## 4. 检查规则

| 规则 | 级别 | 查什么 | 怎么改 |
|---|---|---|---|
| SLK-01 | P1 | 丝印文字或线条离同面焊盘不到设定距离（插件孔两面都算） | 挪开，或改小封装丝印 |
| SLK-02 | P1 | 文字线宽、丝印线宽低于工艺下限（同一宽度合并成一条） | 加粗 |
| SLK-03 | P1 / P3 | 字高低于工艺下限；笔画比例细于 1:8（P3） | 加大字号，或改成只印关键器件 |
| SLK-04 | P1 | 丝印超出板框 | 挪回板内 |
| SLK-05 | P2 | 同面两段文字重叠 | 错开 |
| SLK-06 | P1 | 按位号策略应该印的位号没有显示（策略“只印关键器件”时只查芯片、接口、晶振、按键、二极管、电池、电感等） | 显示并摆到器件旁边 |
| SLK-07 | P2 | 位号离自己器件 > 3 mm，或离别的器件更近（指认不清） | 贴着自己的器件放 |
| SLK-08 | P2 | 文字在同面器件本体下面，贴片后看不到 | 挪到器件旁边 |
| SLK-09 | P2 | 文字方向不在允许的读向里（倒着、斜着） | 转到 0° 或 90° |
| SLK-10 | P1 | 底面文字没有镜像 | 设为镜像 |
| SLK-11 | P1 | 极性器件（二极管、电池、极性电容、≥ 4 脚芯片、≥ 3 脚接口）1 脚附近没有标记 | 在 1 脚旁加圆点、横杠、+ 或三角 |
| SLK-12 | P1 | 板名、版本、`labels` 里的说明（在对应器件 6 mm 内）、`warnings` 在板上找不到 | 加上 |
| SLK-13 | P1 / P3 | 选了“指定位置”却没有 `JLCJLCJLCJLC` 占位（P1）；选了默认位置的提醒（P3） | 加占位文字，或接受默认 |
| ANN-01 | P0 | 位号没编号或格式不对（`R?`、`U*`、`C`） | 原理图里重新编号，更新到 PCB |
| ANN-02 | P0 | 位号重复 | 同上；重复的位号不参与丝印几何检查 |
| ANN-03 | P1 | 前缀和器件值的单位不符（R 却是 uF、C 却是 10k） | 核对位号还是值错了 |
| ANN-04 | P2 / P3 | 选了“按位置重新编号”但顺序不对（从上到下、从左到右，5 mm 一行）（P2）；跳号（P3） | 用 EDA 的按位置编号，再反标 |
| ANN-05 | P1 | 与 BOM 不一致（板上有 BOM 没有，或反过来） | 更新 PCB 或重新导出 BOM |
| TDR-00 | P2 | 读不到泪滴（嘉立创扩展）：按策略需要泪滴的连接点数量，提醒人工执行并记录 | 执行泪滴，`teardrops.done` 填“已执行并重新铺铜” |
| TDR-01 | P2 | 按策略需要泪滴的连接点（线宽 < 0.8 × 焊盘或过孔尺寸）没有泪滴（密集板上 EDA 的泪滴工具会因为空间不够跳过一些，所以是风险项，列给用户看） | 执行泪滴并重新铺铜；空间不够的看一眼即可 |
| TDR-02 | P2 | 射频或差分网络的连接点加了泪滴 | 去掉这些泪滴（或把策略改成“保留”） |

KiCad 板子里，泪滴是带 `(attr (teardrop …))` 的铺铜区（KiCad 8 起）；嘉立创 EDA 专业版工程（`epro_import.py` 读 `.epro2`）里是 TEARDROP 记录，两种都能读到；检查器在每个线头外侧 0.15 mm 处看有没有同网络、同层的泪滴覆盖。泪滴区不会被当成铺铜计入覆盖率。

## 5. 在嘉立创 EDA 和 KiCad 里怎么改

- **位号丝印**：嘉立创 EDA 选中器件后在属性面板改位号的字高、线宽、位置和旋转；批量修改用“查找相似对象”。KiCad 用“编辑文本和图形属性”批量改字高线宽。
- **按位置重新编号**：嘉立创 EDA 在 PCB 里用位号重排（按位置）后，从 PCB 反标回原理图；KiCad 用 PCB 编辑器的“按位置重新标注”，再更新原理图。改完重新导出 BOM 和坐标文件。
- **泪滴**：嘉立创 EDA 在工具菜单里执行泪滴（专业版在设置 → PCB → 通用里也可以打开自动添加泪滴）；KiCad 用“编辑泪滴”。泪滴之后重新铺铜。布线再改动就要重新执行。
- **订单号**：在想放的空白处放一行 `JLCJLCJLCJLC`，字高 ≥ 1 mm，下单时选“指定位置”。

菜单名称会随版本变化，以当前版本为准；找不到时让用户截图给你看。

## 6. 扩展读不到的项目怎么人工确认

嘉立创 EDA 扩展 API 能读到文字、位号属性（字高、线宽、位置、旋转、镜像、是否显示）和焊盘，但：

- **泪滴**：没有读泪滴的接口。扩展报告标 `teardrop_source: none`，给出 TDR-00；G5 要求 `teardrops.done` = “已执行并重新铺铜”。
- **封装自带的丝印线**（1 脚圆点、极性横杠）：读不到，SLK-11 不在扩展里跑，靠 `silk.review.polarity_checked` = “已核对”和截图。
- 这两项在扩展“丝印”页会单独列出来，提醒用户自己看。

KiCad 板子交给 `finish_lint.py` 可以全部检查；两边都用的话，以 Python 的结果为准，扩展的结果做日常快速检查。

## 7. 资料来源

- 嘉立创 PCB 工艺参数（丝印线宽、字高、离焊盘距离、镂空字、高精度丝印）：下单页与工艺能力页，数值以当时页面为准。
- KiCad 8 文件格式：泪滴以带 `teardrop` 属性的铺铜区保存；《PCB Editor》手册“Edit Teardrops”。
- IPC-7351 / 常见装配实践：极性标记在贴片后可见、位号贴近器件、统一读向。
