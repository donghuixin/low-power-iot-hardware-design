## 1. 叠层与设计规则

- **层数**：含射频的设计首选 4 层（信号 / 地 / 电源 / 信号）。完整的第二层地平面同时解决了回流路径、50 Ω 走线宽度和去耦回路的问题。2 层板可以做，但 1.6 mm 板厚下 50 Ω 微带线宽约 3 mm，通常改用共面波导并把射频走线做得极短，且地的完整性要靠大量过孔和精心布线维持。
- **阻抗**：50 Ω 射频线、90 Ω USB 差分的线宽由叠层（介质厚度、介电常数、铜厚）决定。向板厂要叠层参数后计算，并在加工文件中标注阻抗控制要求。不要照搬参考设计的线宽，除非叠层相同。
- **板厂能力**：最小线宽/线距、最小过孔与焊环、阻焊桥、是否支持盘中孔(塞孔电镀)、盲埋孔。BGA / WLCSP 的扇出方式决定是否需要 HDI，这直接影响成本。设计规则按板厂的常规能力设置，不要用到极限能力。
- **板厚**：薄板易弯曲，对 IMU 应力和大尺寸 MLCC 开裂不利；板厚也影响板载天线和阻抗线宽。

## 2. 布局顺序

布局决定了八成的性能。按约束强弱依次放置：

1. **结构定位的器件**：连接器、按键、LED、充电触点、电池座/焊盘、固定孔、屏。
2. **天线**及其净空区：板边或板角，远离电池、金属和手握位置。
3. **有物理约束的传感器**：见 `03-sensor-placement.md`。
4. **主控/射频 SoC**：靠近天线，使馈线最短；同时方便晶体和去耦的放置。
5. **电源**：电池入口 → 保护 → 充电 → 稳压，沿电流方向依次排开；开关稳压器远离天线、晶体和模拟电路。
6. **晶体**：紧贴 SoC 引脚。
7. **去耦电容**：紧贴各电源引脚。
8. **其余器件**。

分区原则：射频、数字、模拟、电源开关各占一块区域，噪声源（DCDC、电机驱动、LED 驱动、高速数字）与敏感电路（天线、晶体、模拟前端、高阻节点）分处两端。靠布局分区来隔离，而不是靠切割地平面。

## 3. 射频与天线

射频性能不足等价于功耗增加：链路差会导致重传、提高发射功率，或迫使设计者缩短连接间隔。

### 天线
- **净空区**：按天线手册或模组手册给出的尺寸，净空区内所有层无铜、无走线、无器件、无过孔。内层和底层最容易被忽略。
- **地平面是天线的一部分**：芯片天线、PCB 倒 F 天线、单极天线都依赖地平面作为另一半辐射体，手册会给出推荐的地尺寸和天线相对地边缘的位置。板子远小于参考板时，效率和带宽会下降，谐振频率会偏移，必须重新匹配。
- **周围环境**：电池、屏蔽罩、连接器外壳、螺丝、外壳金属件、FPC 靠近天线都会使其失谐。人体贴近时 2.4 GHz 损耗明显。在最终外壳、装入电池、佩戴状态下调试匹配并测试。
- **模组**：天线一端伸出板边或其下方及两侧全部净空，按模组手册的推荐布局放置，模组不要放在板子中央。
- 天线类型的选择（PCB 天线、芯片天线、FPC 天线、外接天线）在阶段一确定，它影响板形和成本。

### 馈线与匹配
- SoC 射频引脚到其匹配/谐波滤波网络，按该封装的原厂参考设计实现；ANT 引脚本身不一定是 50 Ω。从原厂规定的 **50 Ω 参考点**到天线馈点的馈线按 50 Ω 设计，尽量短而直，不换层；必须换层时在信号过孔旁放地过孔。
- 匹配网络的器件紧凑排列。射频芯片侧的匹配/滤波元件靠近芯片，天线侧的 π 型匹配靠近天线馈点。
- 馈线下方的参考地平面完整，不被其它走线切断；馈线两侧打地过孔。
- 射频走线不靠近板边之外的噪声源，不与数字线平行。
- 为传导测试留接口：射频测试座，或可通过 0 Ω 电阻/电容切换到测试点的焊盘。
- 同时预留陶瓷与外置天线时采用互斥装配或合适的 RF 开关，明确默认配置；不要直接并联两路。选择器件放在分叉根部，避免未选通支路形成长 stub。
- 天线匹配值依赖最终板形和使用环境。装入电池、外壳并模拟佩戴后调谐；除 S11 外，还需检查辐射效率、方向图和实际链路表现。

### 地过孔
- 顶层铺地要用过孔密集连接到地平面，孤立的铜皮会成为寄生天线。过孔间距远小于波长，2.4 GHz 下常用 2–3 mm 以内。
- 板边、射频区域周围、屏蔽罩焊盘下打一圈地过孔。
- 射频芯片的散热焊盘按手册打足地过孔，它同时是射频地。

## 4. 电源完整性

### 开关稳压器
- 找出高频脉动电流回路（降压：输入电容 → 上管 → 下管 → 回输入电容；升压：输出电容 → 二极管/同步管 → 开关管 → 回输出电容），把这个回路面积做到最小：对应的电容紧贴芯片引脚，同层连接，不经过孔。
- 开关节点(SW)的铜面积尽量小（够通流即可），远离敏感走线，不在其下方的相邻层走敏感线。
- 反馈走线从输出电容处取样，远离电感和开关节点。
- 电感选屏蔽型，其下方不走敏感信号；远离天线、磁力计和晶体。
- 输入、输出电容的地与芯片地就近连接到地平面。
- SoC 内置 DCDC 的外部电感电容按厂商参考布局原样放置。

### 去耦
- 电容紧贴它所服务的电源引脚；电流路径应为 电源 → 电容焊盘 → 引脚，而不是先到引脚再拉到电容。
- 电容的接地端就近打过孔到地平面，过孔紧挨焊盘；电源端同理。回路电感取决于回路面积，线短而宽。
- 多颗并联时小容值的最靠近引脚。
- BGA 下方的去耦放在背面正对电源过孔处。

### 大电流路径
- 电池到稳压器、稳压器到射频/电机等负载的路径按峰值电流设计线宽，并核算直流压降（纽扣电池系统中每几十 mΩ 都有意义）。
- 换层处使用多个过孔。
- 储能电容放在负载（射频电源引脚）附近，而不是电池附近。
- 脉冲大电流负载（电机、PPG LED）的供电和回流路径单独从电源入口处引出，不与模拟电路和传感器共用一段地或电源走线。
- 检流电阻、电量计采用开尔文接法，取样线从电阻焊盘内侧引出。

### 地
- 保持至少一层完整的地平面。不要把数字地和模拟地切开再单点连接，除非器件手册明确要求并且你清楚每一路回流电流的路径；多数情况下切割地平面造成的回流绕行比它解决的问题更严重。
- 走线不跨越地平面上的开槽或分割。
- 电池负极、屏蔽罩、连接器外壳的接地方式要明确。

## 5. 信号完整性

### 走线与接点几何复核

自动布线、网格寻路或拼接参考板走线后，从 PCB 源文件按网络、铜层读取线宽、中心线端点和过孔中心。局部图上同时显示铜轮廓和中心线。只有截图时，把疑点标到具体网络和位置，实测尺寸留待源文件确认。

- **阶梯状走线。** 网格寻路可能在水平、竖直和 45° 方向间逐格交替。优先检查连续多次换向且单段短于当地线宽的地方。固定两端和分支，用少量直线、45° 转角或符合弯折要求的圆弧重走。保留必要的焊盘扇出、差分对调长、避障和已锁定的参考板中心线。
- **过孔和 T 接点。** 沿实际来线追到连接处。普通过孔在每个有走线接入的铜层上，让来线中心线到达孔中心。同层 T 接让支线端点落在主线中心线上，必要时在交点分段。特别检查孔内已有短线、外侧长线却停在铜环边的情况。遇到有意偏心的焊盘入口、热焊盘或平面连接，按实际铜形与工艺要求核对有效铜宽。
- **量出搭接。** 对圆头支线垂直接入直线主干且投影落在主干段内的情形，铜边搭入深度等于两线半宽之和减去支线端点到主线中心线的距离。例如，两线均宽 5.10 mil，端点距主线中心 4.48 mil，两段铜虽已导通，却仅搭入 0.62 mil（约 16 µm）。这个数描述几何重叠深度，成品接点宽度和可靠性要结合铜形及加工公差判断。
- **查到一处后扫同类接点。** 按网络、层和坐标列出只靠铜边相交的接点。在分析副本中暂时忽略可疑搭接，比较哪些焊盘失去连通，以此确定修整优先级。对靠铺铜导通的网络另查重铺后的真实铜面和热焊盘辐条。筛查阈值按线宽、坐标精度和板厂能力选取。

**发现直角或擦边入盘时，按整网修整。** 从截图定位网名、焊盘号和层，高亮该网络，沿所有分支追到每只焊盘，再把同样的检查扩到板上其余网络。逐项记录以下几何结果。

1. **走线转角。** 按同层相邻中心线计算夹角，同时检查分支落在长线中部的交点。要求无直角时，把 90° 转弯改成 45° 折线或圆弧，分支以斜线汇入。整段评估新路线和相邻两端的转角，避免只把直角移到下一段。显示取整时使用与坐标精度相符的角度容差。
2. **焊盘入口和线尾。** 普通焊盘的来线中心线应进入有效焊接铜区，有空间时接到焊盘中心。重点查贴角、止于盘外、借相邻圆头搭接和孔内孤立短线。对异形焊盘、开窗和热焊盘，按实际导电区域选入口。逐层检查每个线端是否落在预期焊盘、孔中心、同网中心线或明确设计的平面连接上。复用参考走线时，检查两端及中间分支是否真正处于所需电流路径，清除多余的悬空尾段。
3. **逐网复验。** 对照网表逐焊盘核对，记录受查网名、层、焊盘和过孔数、残留直角及未解决接点。若一处仍然依赖边缘相交，继续修整并重测该整网。另存的局部候选要明确标记，交付采用实际保存重载的版本。

修改后重铺铜，保存并重载 PCB。用回读坐标复核修过的接点、焊盘连通性、异网间距以及到板边和开槽的距离，再运行原生 DRC。DRC 可以在铜边刚刚搭上时报告零项，因此验收时同时保留接点几何结果。

### 信号路径与参考平面

低功耗 IoT 板上的信号速率不高，问题多来自回流路径、串扰和过快的边沿，而不是传输线效应。

- **回流路径**：每根信号线下方都要有连续的参考平面。换层时，如果参考平面改变，在信号过孔旁加地过孔。跨分割的走线是辐射和串扰的主要来源。
- **边沿速率**：MCU 的 GPIO 边沿可快至 1 ns 量级，即使时钟只有 1 MHz 也会产生高次谐波，落入 2.4 GHz 频段降低接收灵敏度。SPI 时钟、显示接口等在源端串联 22–33 Ω 电阻，或在固件中降低引脚驱动强度。
- **串扰**：时钟和快沿信号远离天线、晶体、模拟输入和高阻节点；平行走线间距至少 3 倍线宽，或中间隔地。
- **USB**：D+/D− 按 90 Ω 差分走线，等长，紧耦合，不跨分割，ESD 器件贴近连接器且走线直接穿过其焊盘。
- **高速存储接口（QSPI Flash、SDIO）**：走线短且长度相近，参考平面完整。
- **I2C 外接**：长线电容大，降速并加保护。
- **复位、唤醒等异步敏感信号**：远离噪声源，必要时加小电容滤波，走线不要沿板边长距离布置。
- **天线下方和附近不走任何信号。**

## 6. 晶体

- 紧贴 SoC 的振荡器引脚，走线短、对称、不换层。
- 负载电容紧贴晶体，其地端就近回到 SoC 附近的地。
- 晶体及其走线下方的相邻层保持完整的地，不走其它信号；周围用地包围并打地过孔。
- 远离开关稳压器、天线、快沿信号和板边。
- 32.768 kHz 振荡回路阻抗极高、驱动极弱，对漏电和串扰非常敏感：走线尤其要短，保持清洁，不在其旁边走跳变的信号。
- 远离热源和机械应力集中处。

## 7. 模拟与高阻节点

- MΩ 级分压、ADC 高阻输入、偏置网络、电容式触摸电极等节点的走线尽量短，相关电阻电容紧贴接收引脚。
- 对极高阻节点用保护环(guard ring)包围，保护环接到与该节点同电位的低阻驱动点。
- **表面漏电**：助焊剂残留和潮气在 µA 及以下的电路中会造成可测量的漏电和漂移。高阻区域要求清洗；阻焊开窗、相邻的不同电位焊盘之间留足间距；必要时涂覆三防漆。
- 模拟走线不与数字线、开关节点平行或重叠。
- ADC 基准的去耦电容紧贴引脚，其地回到模拟地参考点。
- 差分模拟信号成对、等长、紧邻走线。

## 8. 传感器

位置约束见 `03-sensor-placement.md`，layout 时落实：

- **IMU**：远离板边、螺丝孔、连接器、按键和拼板连接点；器件下方按手册要求禁止走线和过孔；焊盘引出线对称，避免大面积铜皮直接连接某一侧焊盘造成焊接应力不均；器件周围不放高器件挤压。
- **温度传感器**：周围开隔热槽，仅用细走线连接；其下方和周围不铺大面积铜；远离发热器件，位于气流上游。
- **磁力计**：远离电池走线、电感、电机走线；大电流的去程和回程走线紧靠在一起以抵消磁场。
- **麦克风 / 气压计**：声孔/气孔位置与外壳对齐；底部进音麦克风的 PCB 开孔周围按手册做环形焊盘，孔内不镀锡堵塞。
- **光学器件**：与外壳窗口的对位公差；发光与接收之间的隔离结构的安装位置。

## 9. EMC / ESD

- ESD 保护器件紧贴接口放置，信号走线先经过保护器件再到被保护芯片；保护器件到地的路径短而宽，直接打过孔到地平面。
- 保护器件之前的走线（可能带高压尖峰）不与内部敏感走线并行。
- 板边一圈地并打过孔；对外连接器的金属外壳按策略接地。
- 外露金属件（按键帽、装饰件、螺丝）要么可靠接地，要么与电路保持足够的间隙。
- 外接线缆的信号在接口处加滤波（串阻、磁珠、电容）。
- 布局时使敏感信号远离板边和外壳缝隙。

## 10. 热

- 线性充电芯片、LDO、功放、LED 驱动的散热焊盘打足过孔连接到大面积铜皮。
- 发热器件远离电池、温度传感器、IMU、晶体。
- 锂电池附近的温升要低于其允许的充放电温度。
- 小型密闭外壳内热量散不出去，充电时的温升要在整机上测。

## 11. 可制造性、可装配性、可测试性

### 封装与焊接
- 每个封装对照 datasheet 的推荐焊盘核对：引脚 1 方向、引脚顺序（特别是晶体管、二极管、连接器镜像）、焊盘尺寸、散热焊盘。
- QFN / LGA 的中心焊盘钢网分割开窗，防止器件浮起；盘中孔必须塞孔，否则漏锡。
- 0201 / 0402 两端焊盘的铜面积和走线宽度对称，防止立碑。
- 大尺寸 MLCC 不放在板边、分板线附近和易弯曲处，长边垂直于弯曲方向的应力。
- 器件到板边、器件之间的间距满足贴片和返修要求；高器件不遮挡矮器件的焊接和检查。
- 手焊原型与机贴量产的间距要求不同，原型阶段可为调试适当放大间距和增加测试点。

### 拼板与工艺
- 基准点(fiducial)：板上至少三个，细间距器件旁加局部基准点。
- 工艺边、定位孔、拼板方式（V 割或邮票孔）；分板应力远离 MLCC、IMU、晶体和天线。板载天线所在的板边不要留邮票孔残留。
- 阻焊桥、过孔盖油/塞油要求；丝印标注极性、引脚 1、位号、版本号、测试点名称。
- 表面处理：细间距和 BGA 用沉金(ENIG)；按键触点、充电触点按耐磨和耐腐蚀要求选择。

### 可测试性
- 测试点：每一路电源、地（多个）、SWD、复位、串口、关键控制信号。测试点做在同一面，间距适合针床。
- **电流测量**：电池入口和每一路电源串联 0 Ω 电阻或跳线焊盘，可断开接入电流表；这是定位睡眠漏电的必要条件。
- 关键的上下拉、使能、匹配网络使用独立的电阻位置，便于修改。
- 为可能需要的器件预留不贴(DNP)位置：串阻、滤波电容、匹配元件、备用储能电容。
- 射频传导测试点。
- 烧录接口适配量产夹具。

### 装配
- 电池连接方式（焊线、连接器、弹片）及其机械强度和防反设计。
- 连接器、按键有通孔脚或加固焊盘承受外力。
- 与外壳的 3D 干涉检查：最高器件、电池厚度膨胀余量、FPC 弯折半径、螺丝柱位置。
- 需要点胶、涂覆、屏蔽罩的区域留出空间，并确认它们不影响天线、传感器和气孔。

## 12. 软板与软硬结合板

- 弯折区不放器件和过孔，走线垂直于弯折线，铜皮用网格，走线拐角用圆弧。
- 软硬交界处走线加泪滴，器件远离交界。
- 补强板(stiffener)的位置与厚度；连接器金手指的厚度公差。
- 动态弯折与一次性弯折的设计要求不同，向用户确认使用方式。
- FPC 上的地参考较弱，射频与敏感模拟信号尽量留在硬板上。

## 13. 审查时需要的材料

开始 layout 审查前确认已有：

- 各层图（或 PCB 源文件），含阻焊和丝印
- 叠层与阻抗要求、板厂工艺能力
- 对应的原理图
- 天线/模组的手册及其推荐布局
- 外壳与电池的位置、材料
- 关键器件手册中的 layout 建议（SoC、DCDC、IMU、晶体）

缺少的材料列入报告的"评审所依据的假设与缺失信息"。只有截图时，说明哪些项目无法从截图判断（内层、净空区的所有层、阻抗）。
