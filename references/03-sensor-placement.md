# 传感器与关键器件的放置约束

这些约束必须在定板形之前确定。它们来自物理原理，原理图上看不出来，layout 完成后也很难补救。

## 1. IMU（加速度计 + 陀螺仪）

### 是否必须放在中心？

取决于测的是什么，原因在于两种传感器对位置的敏感性不同：

- **陀螺仪**测角速度。刚体上任何一点的角速度相同，所以陀螺仪放在哪里读数都一样，位置不重要，重要的是轴向对齐和安装刚性。
- **加速度计**测的是所在点的比力。偏离转动中心 r 时，读数为
  `a_测 = a_质心 + α × r + ω × (ω × r)`
  即多出切向项（角加速度 × 距离）和向心项（角速度² × 距离）。例如偏心 5 cm、角速度 10 rad/s（约 570 °/s）时，向心项为 5 m/s²，约 0.5 g。

据此判断：

| 应用 | 位置要求 |
|---|---|
| 需要物体整体的平动加速度，且物体会快速转动（无人机、平衡车、惯性导航、球类/器械内置） | 尽量靠近转动中心或质心；做不到则在固件中用已知杆臂 r 和陀螺数据补偿（角加速度需对陀螺微分，噪声较大） |
| 姿态估计（静态或低动态下用重力方向） | 偏心会在转动时污染重力估计，高动态场景下尽量靠近中心，低动态影响不大 |
| 只用陀螺（角速度、转动手势） | 位置任意 |
| 计步、活动识别、敲击/跌落检测、手势 | 位置不关键，算法通常针对佩戴位置训练；重要的是与被测体刚性耦合且位置固定 |
| 振动监测 | 靠近振源并刚性安装；注意安装结构的谐振频率要远高于关心的频段 |
| 多个 IMU 测形变或关节角 | 各自位置由被测结构决定，需要标定相对安装姿态 |

向用户确认：测量对象是什么、会不会转动、转多快、要的是平动还是姿态。然后明确告诉用户偏心带来的误差量级，让他决定是移位置还是软件补偿。

### 无论放哪里都要遵守的约束

- **刚性耦合**：IMU 测的是 PCB 的运动。PCB 相对外壳晃动、软排线上的小板、泡棉垫都会引入伪运动和谐振。
- **远离机械应力**：封装应力会使零偏漂移。不要放在板边、螺丝孔、卡扣、连接器、按键、拼板 V 割/邮票孔附近，不要放在会弯曲的区域。板子四点固定时，中部应力通常最小。
- **远离热源与温度梯度**：零偏随温度漂移。远离充电芯片、稳压器、功放、主控，避免一侧受热。
- **远离振动与冲击源**：振动马达、扬声器、蜂鸣器、按键。
- **轴向**：器件轴与产品坐标轴对齐，至少是 90° 的整数倍；在丝印和文档中标明方向。
- **焊接**：按手册的焊盘设计；多数手册要求器件下方不走线不打孔、焊盘走线对称，不要使用底部填充胶。
- **电源**：IMU 的电源噪声会直接进入读数，按手册去耦；若对其做电源开关，注意启动时间和陀螺稳定时间（可达数十 ms）。

## 2. 磁力计

- 远离磁性与铁磁材料：扬声器、振动马达、磁吸充电头、钢壳电池、屏蔽罩、螺丝。
- 远离大电流和变化电流的走线：电流产生磁场，电池线、DCDC 电感、电机线都会造成读数随负载变化。
- 硬铁/软铁干扰需要整机状态下校准，并在产品中提供校准流程。

## 3. 温度 / 湿度传感器

- 测环境时，自发热和板上热源是主要误差来源。放在板边或伸出的"半岛"上，周围开槽做热隔离，减少铺铜连接，远离稳压器、充电芯片、主控、射频功放、显示背光。
- 需要与外界空气流通，外壳开孔；防水时用透气膜。
- 低占空比采样可以降低自发热。
- 测体表温度时相反，需要良好的热接触和对环境的隔热。

## 4. 气压计

- 需要与外界气压连通；密封外壳要有透气孔或防水透气膜。
- 部分器件对光敏感，开孔不要让光直射到芯片。
- 远离热源；按压外壳、风吹会引起读数跳变，需要在结构和算法上处理。

## 5. MEMS 麦克风

- 声孔与外壳之间需要密封的声学通道，漏气会造成频响异常和啸叫。
- 底部进音的型号需要在 PCB 上开孔，孔周围按手册做焊盘环和阻焊。
- 远离扬声器和振动源；电源噪声会进入音频，需独立滤波。
- 常开语音唤醒的方案要关注麦克风的低功耗模式电流。

## 6. 光学传感器（PPG、环境光、接近）

- 发光与接收之间需要光隔离，防止不经皮肤的直通光。
- 窗口材料、厚度、空气间隙决定信噪比；需要与结构一起设计。
- PPG 的 LED 驱动是脉冲电流（几十到上百 mA），其电源和地回路要与模拟前端分开考虑，并计入峰值电流。
- 贴肤稳定性和压力直接影响信号质量，这是结构问题而非电路问题。

## 7. 生理电极 / 高阻模拟前端

- 输入阻抗极高，走线要短，使用保护环(guard)，保持清洁，避免助焊剂残留。
- 需要输入保护（ESD、除颤场景另议），保护器件的漏电流和电容要在信号允许范围内。
- 接触人体时注意漏电流与安规要求。

## 8. 天线

- 放在板边或板角，朝向远离人体和金属的一侧。
- 按天线手册留出净空区（所有层不铺铜、不走线、不放器件）。
- 芯片天线和 PCB 天线的性能依赖地平面尺寸，板子很小时效率下降，需要预期到并留出匹配调试位置。
- 电池、屏幕、金属外壳、屏蔽罩、手握位置都会影响天线；在结构定型前与结构工程师确认。
- 详见 `07-layout.md` 的射频部分。

## 9. 其它

- **按键、连接器、充电触点**：位置由结构决定，需要 ESD 保护就近放置，并做机械加固（通孔脚或加固焊盘）。
- **电池**：体积最大的金属体，远离天线；锂电池上方不要有尖锐器件脚；连接器或焊盘要能承受跌落。
- **晶体**：远离板边应力、热源和天线。
- **电感**：DCDC 电感的漏磁会耦合到磁力计、天线和高阻模拟节点，保持距离或选屏蔽电感。
