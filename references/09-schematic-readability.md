# 原理图绘制流程与可读性

原理图是给人读的：评审者、layout 工程师、固件工程师、半年后的自己。读不清的原理图会直接变成错误——看漏的连接、接反的信号、被意外短接的同名网络。可读性规则因此是可靠性的一部分，而不是美观问题。

本文件既用于**指导绘制**（按第 1 节的流程画），也用于**评审可读性**（按第 2–9 节逐项检查）。

## 1. 绘制流程

按顺序进行，每一步完成后再进入下一步。先连线再整理的做法会导致返工，页面也会越画越乱。

1. **先画框图，后定分页。** 从系统框图和电源树出发，把电路划分为功能模块，决定每个模块放在哪一页。分页方案定下后再放器件。
2. **建好符号再放置。** 确认每个器件的符号符合第 5 节的要求（引脚按功能排列、电源引脚可见）。符号不合适先改符号，不要靠绕线去迁就。
3. **区分卫星器件。** 对每个核心器件，打开数据手册的典型应用电路（Typical Application / Reference Design），列出它的卫星器件和各自服务的引脚（见第 3 节"卫星器件"）。这份清单也是之后布局规划里的卫星器件清单。
4. **按信号流向摆放器件。** 每页先放核心器件，再按数据手册推荐电路的形状把卫星器件摆在对应引脚旁；器件之间留出走线和文字的空间。
5. **连线。** 按第 3 节的规则决定每个连接用直连还是标号。
6. **命名网络。** 所有跨页网络、电源、总线和关键信号按第 4 节命名。
7. **整理文字。** 位号、参数值、网络标号逐一挪到不重叠的位置（第 6 节）。这一步单独做，不要指望放置时自动到位。
8. **加注释。** 把设计意图写在图上（第 8 节）。
9. **编号与电气规则检查(ERC)。** 位号标注，ERC 清零或对每个保留的告警给出理由。
10. **导出 PDF 通读。** 按第 9 节的自检方法从头读一遍。

## 2. 分页与页面布局

### 分页
- **一页一个功能。** 典型划分：封面与框图 → 电源输入与充电 → 稳压与电源域 → 主控最小系统 → 射频与天线 → 传感器 → 存储 → 接口与连接器 → 人机交互 → 测试点与调试。小设计可以合并，但同一页内仍按功能分区。
- **首页放系统框图和电源树**，并附页面目录。读者先看懂整体再进入细节。
- **不要为了省页数把页面塞满。** 一页内容多到必须缩小字体或让文字重叠时，拆成两页。
- 页面顺序与信号/电源的流向一致：电源在前，主控居中，外设在后。
- 使用层次化设计时，顶层页就是框图，子页的端口与顶层方块的引脚一一对应。

### 页面
- 每页有完整的标题栏：项目名、页面标题（写功能，如"电源：充电与电源路径"，不要写"Sheet 3"）、版本号、日期、作者、页码（第 x 页 / 共 y 页）。
- 另设修订记录（首页或单独表格）：版本、日期、修改内容。
- 图纸幅面选择以打印后可读为准（常用 A4 或 A3 横向），同一项目各页幅面一致。
- **所有内容位于图框以内**，并与图框和标题栏保持间距。器件、连线、文字不压图框、不进入标题栏区域、不挤在页面边角。

### 页内布局
- **信号流向从左到右**：输入、信号源在左，输出、负载在右。
- **电位从上到下**：电源在上，地在下。电源符号朝上，地符号朝下，不要倒置或横放。
- 电源页按能量流向从左到右排：电池/输入 → 保护 → 充电 → 稳压 → 输出。
- **功能分区**：同一页内的各功能块之间留出明显空白，用虚线框围起并在框的左上角写上标题（如"I2C 上拉""电池电压检测"）。
- 一个器件的外围电路（去耦电容、上下拉、晶体、滤波）画在该器件旁边，靠近它所连接的引脚。**去耦电容画在所服务的电源引脚旁**，不要把全板的电容堆成一排放在角落——那样 layout 时无法知道哪颗电容属于哪个引脚。确实需要集中绘制时，逐颗标注对应的引脚。
- 同样的电路画成同样的形状（例如每个负载开关、每路电平转换的画法一致），便于对比和发现差异。
- 所有器件引脚和连线端点对齐到统一网格（常用 100 mil / 2.54 mm，细处 50 mil），不使用网格外的连接，避免"看着连上实际没连"。

## 3. 连线：直连、网络标号、端口

原则：**让读者用最少的目光移动看清连接关系。** 同页的近距离连接，一根线最清楚；远距离、跨页、多处扇出的连接，名字比线清楚。两种方式都不应滥用：满页长线和交叉会淹没结构，满页只有标号（每个引脚一个短线头加名字）则完全看不出电路的拓扑。

### 卫星器件：按数据手册推荐电路画，一律导线直连
**卫星器件**是数据手册典型应用电路里挂在某个器件特定引脚上、只为这个器件服务的元件。常见的有：
- 电源引脚的去耦和储能电容、LDO 的输入输出电容；
- 晶体及其负载电容；
- 复位 RC、使能和配置引脚的上下拉；
- DCDC 的电感、自举电容、反馈分压和补偿网络；
- 充电芯片的编程电阻、NTC 电阻；
- 射频匹配和滤波网络、天线馈点的 π 型匹配；
- 紧贴接口的串阻、ESD 器件。

画法：

1. **以数据手册为准识别。** 哪些元件属于哪个器件、挂在哪个引脚，按数据手册推荐电路（或厂商参考设计）确定，不凭印象。手册要求的值和数量（例如每个 VDD 引脚一颗 100 nF）照抄，偏离时在图上注明理由。
2. **照推荐电路的形状摆放。** 卫星器件画在所服务的引脚旁，元件之间的相对位置和拓扑与手册图一致，读者对照手册能一眼认出"这是晶体电路""这是 DCDC 外围"。一个器件的卫星器件可以用虚线框围起来，框标题写主器件位号和功能。
3. **主器件引脚与卫星器件之间、卫星器件彼此之间，全部用导线连接。** 不用网络标号、跨页端口或"接口"式短线头加名字来代替这些连接。即使这个网络需要命名（为了测试点或 layout 约束），名字也只标在已经画出的导线上，不能用标号来代替导线。
4. **卫星器件接电源、接地的一端直接放电源或地符号**，这是正常画法，不属于用标号代替连接。
5. **卫星器件不放到别的页**，也不与其它器件的卫星器件共用。复位、使能这类网络如果还要去别处（排针、另一颗芯片），卫星器件部分照样用导线连，只在向外引出的那一支用标号或端口。
6. **位号尽量连续**，例如 U1 的卫星器件用 C1–C8、Y1、R1–R2，便于 layout 时按组查找。

这样画出的卫星器件分组与布局阶段的卫星器件一一对应：生成布局规划项目（`12-layout-planner.md` 第 3 节）时直接按这些分组填写，layout 时也按同样的分组把它们贴在对应引脚旁。

### 何时直连
- 同一页内、同一功能块内或相邻功能块之间的连接，用导线直连。
- 器件与它的卫星器件（去耦、上下拉、滤波、反馈网络、晶体及负载电容、匹配网络，见上一小节）之间**必须直连**。这些电路的拓扑本身就是信息，用标号替代会让读者无法一眼看出"这是一个分压器"或"这是一个 π 型匹配"。
- 判断标准：导线能在不超过两三个拐弯、基本不与其它线交叉的情况下到达。

### 何时用网络标号或端口
- **跨页的连接**：一律使用跨页端口（off-page connector）或层次端口，并标注对端所在的页码，让读者能直接翻到。
- **电源和地**：使用电源符号，不拉长线。每一路电源使用带名称的独立符号。
- **标准化接口与总线**：I2C、SPI、UART、SWD、USB、QSPI、I2S 等在多个器件间共享或传到多页的信号，用网络标号；成组信号用总线画法或成组排列的标号，各处的排列顺序保持一致。
- **同页但距离远**：直连需要横穿其它功能块、跨越半页以上或造成多处交叉时，改用标号。
- **扇出到多处**（如复位、使能、中断汇总）：用标号。

### 标号的画法
- 标号放在一小段导线上，导线从引脚引出足够长度，标号文字不压在引脚名或符号上。
- 同一页内使用标号的网络，**两端都要在视野内容易找到**；一个标号在本页只出现一次且没有跨页端口，通常意味着漏连或命名笔误，逐个确认。
- 跨页端口按方向选用输入、输出、双向形状，并集中放在页面左右两侧：进入本页的信号在左侧，离开的在右侧。
- 区分全局标号与局部（页内）标号的作用域，按所用 EDA 工具的规则确认：同名的局部标号在不同页是否相连、层次设计中标号是否穿透层次，各工具不同。弄错作用域会造成漏连或意外短接。

### 导线画法
- 只画水平和垂直线，不画斜线。
- **避免四向交叉连接。** 两条线相连时画成两个错开的 T 形连接，使"交叉不相连"与"交叉且相连"无法混淆；连接点（圆点）清晰可见。
- 尽量减少交叉；不可避免的交叉保持垂直相交。
- 导线不穿过符号本体，不压在引脚名、位号或其它文字上，不与其它导线重叠或紧贴平行到难以分辨。
- 导线不沿着符号边缘走，避免看起来像是连到了相邻引脚。
- 连接点落在引脚端点上，不落在引脚中段或符号内部。
- 不连接的引脚放置"不连接"标记，使悬空成为明确的设计决定而不是遗漏。

## 4. 网络命名

- **名称表达功能**，不使用工具自动生成的名字（N$12、Net-(U3-Pad5)）命名任何跨页或关键网络。
- **电源网络带电压和用途**：`VBAT`、`VBUS_5V`、`VDD_1V8`、`VDD_SENS_1V8`（被开关的传感器电源）、`VDDA_3V0`。被开关的电源域与常开电源使用不同的名字，不能因为电压相同就同名。
- **低有效信号统一标记**：全项目只用一种写法（`nRESET`、`RESET_N` 或上划线三选一）。
- **差分对**用 `_P` / `_N` 后缀；总线成员带序号（`QSPI_IO0`…`QSPI_IO3`）。
- **视角明确**：串口等有方向的信号从主控视角命名，或直接写明两端（`MCU_TX_TO_GNSS_RX`），避免 TX 接 TX。
- **带上所属对象**：多路同类信号加前缀区分（`IMU_INT1`、`BARO_INT`、`I2C0_SDA` / `I2C1_SDA`）。
- 电平转换器、串联电阻、开关两侧的网络使用不同的名字（`SPI_CLK` 与 `SPI_CLK_R`、`SDA_1V8` 与 `SDA_3V3`）。
- **防止近似名**：`3V3`、`+3V3`、`VCC3V3`、`VDD_3V3` 混用会生成多个互不相连的网络；大小写、下划线的不一致同理。定稿前导出网表，按名称排序检查相似项和只有一个节点的网络。
- 地网络只在确有需要时才区分（如 `AGND`），并在图上注明它们在何处连接。

## 5. 符号

- **引脚按功能排列，不按封装的物理位置排列**：输入在左，输出在右，电源在上，地在下；同一接口的引脚相邻并按固定顺序排列（如 SCK、MOSI、MISO、CS）。
- **大器件拆分为多个单元**：电源单元、各 IO 组/各功能接口、射频、调试。电源单元单独画并带上全部去耦电容。不要把上百个引脚的器件画成一个方块再向四周拉线。
- **显示全部引脚**，包括电源、地和不连接的引脚。不使用隐藏的电源引脚：隐藏引脚的连接在图上不可见，在多电源域设计中容易连错电源。
- 每个引脚同时显示引脚名和引脚号；多功能引脚的名称写出在本设计中使用的功能（符号上可保留完整复用名，但网络名要说明用途）。
- 分立器件使用标准符号并区分类型：N 沟道与 P 沟道 MOSFET、肖特基与 TVS 与稳压管、极性电容与非极性电容；带体二极管的 MOSFET 符号画出体二极管，便于检查反向导通路径。
- 连接器符号的引脚顺序与实物编号对应，并在旁边注明对接视图或引脚 1 位置。
- 同类被动器件方向一致：串联元件横放，对地/对电源元件竖放。
- 有极性的器件（二极管、电解/钽电容、LED）方向与电流方向一致，自上而下或自左向右。

## 6. 文字与标注的摆放

- **文字不与任何对象重叠**：不压在符号本体、引脚、导线、连接点、其它文字上，也不贴着器件的边角以至于看不出属于谁。每段文字周围留有空白。
- **位号和参数值紧邻所属器件**，位置规则全图一致（例如横放的器件位号在上、参数在下；竖放的器件都在右侧）。相邻器件的文字之间有明确的归属，不出现"这个 100nF 是左边还是右边那颗"的歧义。
- **文字方向只用两种**：水平（从左向右读）和竖直（从下向上读）。不出现倒置或镜像的文字；旋转、镜像器件后逐个纠正。
- 字号全图统一，打印到目标幅面后可读（约等于打印后不小于 1.5 mm 字高）。不靠缩小字号来解决拥挤，拥挤就拉开间距或分页。
- 网络标号文字与所在导线平行并紧贴，不让一个标号看起来同时属于两条相邻的线。
- 引脚名较长时把导线拉长，使标号和引脚名各有位置。
- 注释文字放在所描述电路的旁边，并用功能框或引线明确指向对象；不堆在页面角落与对象分离。
- 文字不压图框、不进入标题栏。
- 不依赖颜色传递信息：图纸应在黑白打印后仍然完整可读。

## 7. 器件参数与位号

- **位号前缀按惯例**：R 电阻、C 电容、L 电感、FB 磁珠、D 二极管、Q 晶体管、U 集成电路、Y/X 晶体、J 连接器、SW 开关、TP 测试点、BT 电池、ANT 天线、F 保险丝。位号唯一、无重复、无未标注的 `R?`。
- **参数值写全到能选型的程度**：
  - 电阻：阻值，精度有要求时标出（反馈分压、检流、分压测量）。
  - 电容：容值；关键位置加耐压、介质和封装（如 `10µF 6.3V X5R 0603`），因为直流偏压降额与这些参数直接相关。
  - 电感：感值、饱和电流、直流电阻或完整料号。
  - 晶体：频率、负载电容、频率容差。
  - 二极管、MOSFET、IC：完整料号。
- 数值写法全图统一（`4.7k` 与 `4k7`、`100nF` 与 `0.1µF` 二选一）。
- **不贴装的器件明确标记** DNP/NC，并注明用途（"调试用，量产不贴""备选匹配位置"）；可选配置的各种贴法列表说明。
- 0 Ω 电阻、跳线、焊盘桥注明作用和默认状态（"电流测量点，默认短接"）。
- 每个器件带齐 BOM 所需的属性：料号、封装、制造商；封装与符号引脚号对应关系已核对。

## 8. 设计意图注释

好的原理图自己能回答读者的问题。以下信息直接写在图上对应位置：

- **电源**：每路电源的电压、最大电流、来源和使能条件；稳压器的输出电压计算式（反馈电阻）；充电电流的设定电阻与计算结果。
- **总线**：I2C 各器件的地址（含地址脚接法）；上拉阻值的依据；SPI 各片选的归属。
- **配置与默认态**：启动配置引脚的电平与含义；地址/模式选择的选项表；上下拉决定的上电默认状态（"EN 默认拉低：上电时传感器电源关闭"）。
- **信号属性**：低有效、开漏、电平域（在电平转换两侧标出电压）；模拟信号的量程与分压比。
- **给 layout 的要求**：`50 Ω 阻抗控制`、`90 Ω 差分`、`紧贴 U1 第 5 脚放置`、`天线净空区`、`开尔文连接`、`远离 DCDC`、`下方禁止走线`、大电流路径的电流值。
- **给固件的信息**：引脚功能表或其所在页的指引、中断极性、需要固件配置才能达到低功耗的器件。
- **给调试和生产的信息**：测试点的名称与预期电压、电流测量点、烧录接口的引脚定义、硬件版本识别电阻的编码表。
- **未定事项**：用醒目的标记（如 `TODO`、`待验证`）标出，并在发布前清零或转入问题清单。
- 参考设计或手册依据：关键电路旁注明"按 xx 参考设计"或手册章节，便于复核。

## 9. 输出与自检

发布前完成以下检查：

1. **ERC**：无错误；每个保留的告警有书面理由。未连接引脚均有不连接标记；电源网络均有驱动源标记。
2. **网表检查**：按名称排序，查找近似名、只有一个节点的网络、不应存在的自动命名网络。
3. **导出可搜索的 PDF**（文字为矢量，位号和网络名可搜索），带书签或页面目录。
4. **通读**：以 100% 缩放从第一页读到最后一页，逐页确认：
   - 不看其它页，能说出本页的功能；
   - 每个跨页信号都能找到去向；
   - 没有重叠或归属不清的文字；
   - 没有四向交叉、斜线、穿过符号的导线；
   - 黑白打印后仍然可读。
5. **请未参与设计的人读一遍**，或隔一天自己重读；读者提出的每个"这里连到哪""这个值是哪颗的"都是需要修改的可读性问题。
6. 标题栏的版本、日期与修订记录已更新，各页一致。

## 10. 评审时如何分级

可读性问题按它引发错误的可能性分级，而不是一律归为建议：

| 情况 | 级别 |
|---|---|
| 可读性问题已经造成电气错误：同名标号意外短接两个网络、近似名导致漏连、标号作用域用错、四向交叉实际未连接、连线未落在引脚上 | P0 |
| 极易引起误读或误操作：隐藏电源引脚、串口方向不明、低有效标记不一致、DNP 未标记、去耦电容与引脚的对应关系不明、电源域同名 | P1 |
| 影响评审效率和后续维护：文字重叠、布局混乱、一页多功能、缺少注释、标号滥用导致拓扑不可见、卫星器件用网络标号连接或画到别处、卫星器件与数据手册推荐电路对不上 | P2 |
| 风格统一性：字号、数值写法、位号顺序 | P3 |

评审报告中把可读性问题单独列为一节，与电气问题分开，便于用户分别处理。
