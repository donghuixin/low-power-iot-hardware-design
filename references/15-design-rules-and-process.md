# 设计规则与板厂工艺：怎么写规则、怎么对照价格档位

设计规则决定三件事：板子做不做得出来、要花多少钱、DRC 报出来的东西值不值得信。本文件讲怎么把规则写好，并说明配套工具 `scripts/fab_rules.py` 的用法：它读取板厂工艺（内置嘉立创，也可导入用户自己的板厂）、读取设计里的规则和实际尺寸，再把二者对照，指出落在哪个价格档、怎么改能省钱。

写规则的方法部分，来自对 CADET（[LGAI-Research/CADET](https://github.com/LGAI-Research/CADET)）的阅读：它要在 KiCad 引擎里生成 10 万块"零违规"的板子，所以把"规则怎么定义、怎么检查、怎么验收"做得很明确。布线过程本身见 `14-routing-practice.md`。

## 1. 何时用

- **阶段一（需求与选型）**：层数、最小封装间距定下来后，看一眼目标档位，估算打样成本。
- **阶段三开始布局布线前**：按目标档位生成规则和网络类，先填进 EDA 再动手布线。
- **布线后、下单前**：读出设计里的规则和实际用到的最小线宽、过孔，对照工艺档案，确认档位和超限项。
- 用户问"嘉立创能不能做 3.5 mil""0.2 的孔要不要加钱""换成别家板厂行不行"时。

## 2. 写好规则的八条做法

**1. 规则分三层，谁管什么要分清。**

| 层 | 内容 | 来源 | 写在哪 |
|---|---|---|---|
| 板厂下限 | 做不出来的界线：最小线宽线距、孔、焊环、板边距 | 工艺档案 | 全局约束 / 自定义规则 |
| 设计默认 | 日常使用的数值，比下限宽 | 团队习惯、目标价格档 | Default 网络类 |
| 电气要求 | 电流线宽、阻抗线宽、高压间距、差分间距 | 计算和器件手册 | 专门的网络类或条件规则 |

电气规则只能比板厂下限更严。板厂下限只说"能做"，不说"好用"。

**2. 一个网络类是一组配套的数，不是四个独立的数。** CADET 给每个网络抽"规则向量"时，线宽、间距、过孔外径、过孔孔径是从同一块真实板子里成组取的，不会各取各的。自己写网络类时也要成组核对：过孔外径至少比孔径大 0.2 mm；电源类线宽加大时，过孔也要跟着换大孔；间距不要小于同档位的线宽下限。

**3. 两个对象之间的间距取较严的一方。** CADET 判断"能不能过"时，对每块别的铜，用的是 max(本网络间距, 对方间距)。写规则时按这个口径想：高压网络设了 0.6 mm，普通信号靠近它时也必须是 0.6 mm。如果 EDA 的优先级让宽松的规则盖过了严格的，就要调整规则顺序或加条件。

**4. 板边、钻孔、过孔是单独的规则。** 它们不能靠"线距"一条带过。CADET 里板边间距取 max(0.3 mm, 网络间距)，过孔到别的钻孔另有一条。至少分别写出：铜到板边、孔到孔、孔到铜、过孔焊环、插件孔焊环。

**5. 特例用带范围的规则，不放松全局。** BGA 扇出需要 3 mil 时，写一条只在该区域或该网络类生效的规则，全局仍保持常规值。全局下限一旦放松，别处不小心画出的细线不会再被报出来，板子也会无声无息地掉进更贵的档位。

**6. 严重等级要有意设定，交付前用"严格口径"再查一遍。** KiCad 的默认设置里，悬空线头、悬空过孔、孔间距、孤立铜都只是"警告"。CADET 在布线过程中允许暂时忽略"未连接"，但接受一步结果之前的严格检查，把悬空线头也算作违规；最终验收是"全部连通，并且错误级违规为零"。实际做法：
- 布线过程中可以只盯错误级。
- 交付前把悬空线头、悬空过孔、孔间距、孤立铜、铜皮碎片当作必须清零的项目，不因为它们是警告就略过。
- 确实要保留的例外逐条写明理由，不用"降成忽略"的办法让报告变干净。

**7. 规则要贴着实际需要，不留没用的余地。** 板上实际最小线宽是 0.15 mm，全局下限却写 0.09 mm，等于给以后的改动留了一个不会报警的口子。布完线后把下限收紧到实际用到的数值；`fab_rules.py check` 会指出"实际落在便宜档、规则允许到贵档"的情况。CADET 用同样的思路校准它的生成器：先设参数，再量实际结果，然后把二者对齐。

**8. 规则跟着工程文件走，验收在干净的环境里重做。** CADET 把每块板的规则写在工程文件里，最后在全新启动的引擎上重放、重新检查，通过才算数。对应到实际工作：规则保存在工程里（KiCad 的 `.kicad_pro` 和 `.kicad_dru`、嘉立创 EDA 的工程规则），不依赖某台电脑上的软件默认值；交付前关掉重开工程、重铺铜、重跑一遍 DRC。评估可行性时用保守的数（留余量），最终判定以 EDA 的 DRC 和板厂审核为准。

## 3. 工艺档案与价格档位

工艺档案是一个 JSON 文件，记录某家板厂的能力下限、价格档位、价格参考和来源。内置档案是 `assets/fab-profiles/jlcpcb.json`（嘉立创 FR-4 刚性板，检索日期 2026-11-24）。

**档位**按线宽、线距、过孔三样划分，从便宜到贵排列。嘉立创档案的四档是本 skill 做的归纳，不是嘉立创的官方分级：

| 档位 | 1–2 层：线宽/线距，过孔 孔径/外径 | 4 层及以上 | 成本 |
|---|---|---|---|
| 经济 | 0.127 / 0.127，0.3 / 0.6 | 0.127 / 0.127，0.3 / 0.6 | 官方建议的最低成本范围，最接近免费打样和特价板的条件 |
| 标准 | 0.10 / 0.10，0.3 / 0.45 | 0.09 / 0.09，0.2 / 0.45 | 常规能力内，不加价 |
| 加价 | 0.10 / 0.10，0.15 / 0.25 | 0.09 / 0.09，0.15 / 0.25 | 孔 < 0.3 mm 且外径 ≤ 0.4 mm，或 0.15 mm 孔：下单系统加价 |
| 极限 | 0.10 / 0.10，0.10 / 0.20 | BGA 局部 0.076，0.10 / 0.20 | 更贵，要求板厚 ≤ 1.0 mm、沉金或 OSP |

单位 mm。几条容易记错的：

- 多层板过孔外径 ≥ 0.45 mm 时，0.2 mm 的孔不加价；2 层板想不加价，孔要 ≥ 0.3 mm。
- 2 oz 铜的最小线宽线距变成 0.16 mm（2 层）/ 0.15 mm（多层）。
- 盘中孔（树脂塞孔加电镀盖帽）在 6 层及以上是标配、免费，2 层和 4 层收费。
- 6 层及以上不能做喷锡；0.2–0.25 mm 的 BGA 焊盘要沉金。

各档相同的其余下限（焊环、孔到孔、孔到线、板边距、阻焊桥、丝印等）和价格参考，运行 `python scripts/fab_rules.py show` 查看，不在这里重复。

**关于价格**：档案里记了检索到的板费单价和几项附加费，每项都带日期和来源。加价档的具体金额没有公开的固定数字，随面积、数量和订单类型变化，所以只标"是否加价"。向用户报成本时，说清楚这是哪一天查到的数，并提醒以下单系统的实时报价为准。

**更新档案**：嘉立创的工艺和价格经常调整。用户要下单，或档案的检索日期已超过三个月时，重新查官方工艺页和计价页，更新 JSON 里的数值、`retrieved` 和各价格项的 `as_of`。

## 4. 用 `fab_rules.py`

```bash
python scripts/fab_rules.py show [--profile 档案.json] [--layers 4]     # 看档位、下限、价格参考、来源
python scripts/fab_rules.py emit --tier standard --layers 4 -o rules/   # 生成 fab.kicad_dru 和 netclasses.md
python scripts/fab_rules.py read board.kicad_pro board.kicad_pcb        # 读出规则、网络类、严重等级、实际尺寸（JSON）
python scripts/fab_rules.py check board.kicad_pro board.kicad_pcb -o 对照.md
```

**读取设计（`read` / `check` 接受的文件）**

| 文件 | 读到什么 |
|---|---|
| `.kicad_pro` | 全局下限、网络类（线宽、间距、过孔）、各检查项的严重等级 |
| `.kicad_pcb` | 铜层数；实际用到的各种线宽、过孔规格及数量；插件孔最小孔径和焊环 |
| `.kicad_dru` | 自定义规则列表 |
| 铜皮数据包（`extract_copper.py` 的输出） | 实际线宽（Gerber 路线的过孔尺寸不可靠，需另行确认） |
| 规则表（CSV / Markdown / 键值文本 / JSON） | 嘉立创 EDA 等其他工具：让用户把设计规则抄成"参数, 数值"的表，按参数名匹配 |

嘉立创 EDA 的工程规则没有直接解析。两种办法：让用户把"设计规则"里的数值贴出来或截图，由 Claude 整理成规则表；或导出 Gerber 后用铜皮数据包读实际线宽。

**对照报告（`check`）给出：**

- 价格档位，以及是哪个参数把板子推到这一档的。
- 降档办法：把哪个数改到多少，就能回到便宜一档。
- 每种过孔规格、最小线宽分别落在哪一档。
- 问题列表：超出能力（P0）、规则小于工艺下限或自相矛盾（P1）、规则比实际松或焊环偏小（P2）、在下限与建议值之间或严重等级偏松（P3）。
- 有 P0 时命令返回 1。

**生成规则（`emit`）** 输出两个文件。`fab.kicad_dru` 是板厂下限的 KiCad 自定义规则，粘贴到"电路板设置 → 自定义规则"后，用 KiCad 的语法检查确认一遍（脚本的输出没有在 KiCad 里实测过）。`netclasses.md` 是四个网络类的建议表：信号、电源、射频、细间距扇出。它们只是起点：电源线宽按电流核算，射频线宽按叠层计算。`--margin 0.02` 可以在工艺下限上再加余量。

## 5. 用户自己的板厂工艺

用户用别家板厂，或嘉立创给了专门的工艺说明时，把它导入成工艺档案：

```bash
python scripts/fab_rules.py template > 工艺表.csv        # 空白表：参数 × 档位
python scripts/fab_rules.py import 工艺表.csv -o myfab.json
python scripts/fab_rules.py check board.kicad_pro board.kicad_pcb --profile myfab.json
```

- **能直接导入的格式**：CSV、TSV、Markdown 表格、"参数: 数值"的文本、xlsx（需要 openpyxl），以及按本格式写好的 JSON。
- 参数名按中英文别名匹配（"最小线宽""Min trace width""过孔内径"等），数值可以带 mil、mm、μm。
- 表里有多列数值时，每列是一个档位，按从便宜到贵排列，第一行是档位名。"备注"列会被忽略。
- **没认出来的行会列出来**，不会被悄悄丢掉。逐行核对：是参数名没匹配上，还是确实与规则无关（例如表面处理）。
- **PDF、截图、网页**：Claude 先读出数值，填进模板再导入。读不清或单位不明的数值向用户确认，不要猜。
- 线宽、线距、过孔孔径、过孔外径四项是划档位必需的。缺了哪项，导入结果的说明里会写明。
- 导入的档案没有价格信息时，报告只说档位名。金额请用户向板厂确认后补进 `pricing`。

## 6. 写进评审

- 在"评审所依据的假设"里写明：对照的是哪份工艺档案、检索日期、按几层几盎司铜。
- 把对照报告的档位、决定档位的参数和降档办法写进"成本与可制造性"；P0、P1 进问题列表。
- 加价档或极限档是设计必需的（例如 0.4 mm 间距 BGA），写明原因和影响到的区域；不是必需的，给出回到标准档的改法。
- 价格只引用档案里带日期的数字，并提醒以实时报价为准。

## 7. 局限

- 线距没有从 PCB 里实测，只读了规则和网络类。实际最小线距以 EDA 的 DRC 为准。
- 档位只按线宽、线距、过孔划分。板厚、铜厚、表面处理、颜色、阻抗、半孔、拼板、交期等也会影响价格，脚本只在档案的"可选项"和"价格参考"里列出，不参与划档。
- 嘉立创的档位划分是归纳，加价金额未量化。免费打样条件来自第三方整理，未在官方页面核实。
- 只覆盖 FR-4 刚性板的常用范围。软板、铝基板、HDI、高频板材需要另建档案。
- `fab.kicad_dru` 用的是 KiCad 自定义规则的常见写法，没有在 KiCad 里跑过，不同版本可能要微调。
