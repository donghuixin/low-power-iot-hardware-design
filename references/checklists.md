# 逐项核对清单

每个阶段收尾时扫一遍，确认没有遗漏。清单只列"查什么"，原因和做法在对应参考文件中。不适用的项目标注"不适用"而不是跳过，这样用户能看到它被考虑过。

## A. 需求（阶段一）

- [ ] REQ-01 续航目标已量化，并明确充电/更换方式
- [ ] REQ-02 应用层数据率已计算，无线方案的吞吐有至少一倍余量
- [ ] REQ-03 通信对端、距离、环境、延迟要求已明确
- [ ] REQ-04 电池化学体系、容量、尺寸已确定，峰值电流能力已核对
- [ ] REQ-05 所有器件的电压范围与电源架构匹配
- [ ] REQ-06 尺寸、重量、外壳材料、防水等级已明确
- [ ] REQ-07 工作与存储温度范围已明确
- [ ] REQ-08 传感器的量程、噪声、带宽、采样率已明确
- [ ] REQ-09 传感器与天线的放置约束已列出并反映到板形
- [ ] REQ-10 固件升级方式与存储空间
- [ ] REQ-11 离线数据缓存的容量与存储器类型
- [ ] REQ-12 计时精度与是否需要低频晶体
